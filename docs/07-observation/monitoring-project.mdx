# Monitoring your project

> Sofía Acuña, Marilyn Manrow, Brandon Madriz

As your project progresses, the **Project overview** becomes the primary place for tracking implementation activities and monitoring progress across the trial life cycle.

Project owners can use the **Project overview** to:

* Monitor participant registration progress.
* Review the status of trial package preparation and distribution.
* Track active and completed data collection moments.
* Monitor data submission progress throughout the evaluation cycle.
* Verify the completion of trial documentation.
* Access project actions as they become available.
* Download participant registration and assessment datasets in both **Raw** and **Shareable** formats (See Shareable data).

Many actions in ClimMob are enabled only after specific requirements have been completed. For example, technology randomization requires technologies and participant registration forms to be configured, while publication requires completed trial documentation and a closed project.

Regularly reviewing the **Project overview** can help identify incomplete activities, monitor project progress, and determine when the project is ready to move to the next stage.
