# Start a data collection moment

A data collection moment defines a specific stage of the trial when observations are collected from participants. Before data collection can begin, the corresponding trial data collection form must be prepared, and the trial packages must have been distributed to participants 

Before starting a data collection moment, ensure that the following activities have been completed:

* Trial packages have been prepared and distributed to participants.
* Participants have been registered.
* The **trial data collection form** has been configured, including all required questions for the selected data collection moment.

How to:

1. From the **Project overview**, locate the data collection moment you want to start.
2. Open the available actions and click **Start data collection moment**.
3. Confirm that the data collection moment is ready to begin.
4. Once started, field agents can begin collecting observations from participants.

After starting an assessment, field agents can collect data using the available data collection methods.

See **Data collection** for instructions on collecting observations using ODK Collect or Excel upload.
