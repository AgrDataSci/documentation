| ✔ | Hatua            | Kazi             | Vitendo Muhimu                                                                                           | Mhusika             |
|---|------------------|-----------------|-----------------------------------------------------------------------------------------------------|-------------------------|
| ☐ | **1.Maandalizi** | Elezea upeo     | Tambua matatizo ya eneo; chagua chaguo za teknolojia; amua vigezo vya tathmini; amua eneo lengwa na idadi ya wakulima | Watafiti + Watekelezaji |
| ☐ |                | Andaa vifaa | Zalisha mbegu/pembejeo zenye ubora; andaa kadi za uchunguzi, vijitabu, na vifaa vya mafunzo             | Watafiti             |
| ☐ | **2.Muundo**  | Unda mradi katika ClimMob | Sajili akaunti; sanidi mradi kwa kutumia SOP; weka mawakala wa uwanjani; ingiza chaguo za teknolojia; pitia maswali ya ukusanyaji data | Watekelezaji            |
| ☐ |                | Nasibu na vifurushi | Tengeneza vifurushi vya majaribio vilivyo na misimbo ya QR; andika lebo kwenye mifuko; andaa seti zilizo na usawa                              | Watekelezaji            |
| ☐ | **3.Uandikishaji** | Uteuzi wa wakulima | Tambua wanaojitolea (wanaume/wanawake, umri tofauti na majukumu); hakikisha kujitolea                            | Mawakala wa uwanjani            |
| ☐ |                | Uhamasishaji     | Ufikio kupitia mikutano, mabango, mdomo kwa mdomo                                                         | Mawakala wa uwanjani            |
| ☐ | **4.Usambazaji** | Warsha ya mafunzo | Fundisha wakulima mbinu ya tricot, usanidi wa majaribio, na kadi za uchunguzi                                    | Watekelezaji + Mawakala wa uwanjani |
| ☐ |                | Sambaza vifurushi vya majaribio | Toa vifurushi vilivyo na msimbo wa QR vyenye chaguo 3, kadi ya uchunguzi, na kijitabu                              | Mawakala wa uwanjani            |
| ☐ |                | Sajili wakulima | Tumia ODK Collect kurekodi maelezo ya mkulima na msimbo wa kifurushi                                             | Mawakala wa uwanjani            |
| ☐ | **5.Utekelezaji** | Majaribio shambani   | Wakulima hupanda/kusimamia vipande 3 kando kwa kando chini ya mazoea ya kawaida                                      | Wakulima                 |
| ☐ | **6.Uchunguzi** | Tathmini za uwanjani | Wakulima hurekodi "bora zaidi" na "mbaya zaidi" kwa kila kigezo kwenye kadi za uchunguzi                             | Wakulima                 |
| ☐ |                | Ufuatiliaji        | Toa vikumbusha/msaada kupitia simu/ziara; saidia kujaza kadi inapohitajika                        | Mawakala wa uwanjani            |
| ☐ | **7.Ukusanyaji** | Kusanya data     | Mawakala wa uwanjani hukusanya kadi za uchunguzi/data; ingiza kupitia ODK Collect; pakia kwenye ClimMob                  | Mawakala wa uwanjani            |
| ☐ | **8.Uchambuzi** | Shughulikia data     | Tumia ClimMob kutengeneza ripoti (mwelekeo wa teknolojia, uchambuzi wa vigezo vya maelezo)                  | Watekelezaji            |
| ☐ |                | Matokeo          | Tengeneza ripoti ya uchambuzi (watafiti) + vipeperushi vya taarifa (wakulima)                                          | Watekelezaji            |
| ☐ | **9.Maoni** | Warsha za mwisho  | Shiriki matokeo ya jumla; sambaza vipeperushi vya taarifa; wezesha majadiliano ya vikundi vya wakulima                     | Watekelezaji + Mawakala wa uwanjani |
| ☐ |                | Mafunzo ya vitendo | Toa masomo ya ziada ya kilimo (k.m., uhifadhi wa mbegu)                                              | Watekelezaji            |
| ☐ | **10.Tathmini** | Tathmini mzunguko     | Kusanya maoni ya wakulima na mawakala; tathmini viashiria (kiwango cha ukamilishaji, uwiano wa jinsia, ukubaliaji, ushiriki wa kurudia, uenezaji) | Watafiti + Watekelezaji |
| ☐ |                | Panga mzunguko ujao  | Rekebisha dimbwi la teknolojia (acha chaguo duni, ongeza mpya); panua ushiriki wa wakulima                      | Wadau wote        |
