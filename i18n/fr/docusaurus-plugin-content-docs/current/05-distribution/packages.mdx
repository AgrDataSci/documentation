# Packages d'essai

> Sofía Acuña, Marilyn Manrow, Brandon Madriz, Kauê de Sousa

### Préparer les packages d'essai

Une fois vos technologies randomisées dans ClimMob [(cliquez ici pour l'étape « Randomisation des technologies » dans ClimMob)](/design/climmob-setup#technology-randomization), l'étape suivante consiste à créer les packages physiques contenant les technologies que les participants utiliseront pour les tests en aveugle.

Comment faire (trois étapes) :

1. Rassembler les matériaux

* Collectez des quantités suffisantes de chaque option technologique que vous testez.
* Exemple : Si vous testez des variétés de semences, rassemblez des quantités suffisantes de chaque type de semence.

2. Télécharger les listes de packages depuis ClimMob (dans la section Téléchargements) :

* Liste des packages d'essai randomisés → indique quelle combinaison de trois options technologiques est incluse dans chaque package.
* Liste des packages avec codes QR pour l'enregistrement des participants → contient le numéro de package et son code QR unique.

3. Préparer et étiqueter les packages

* Assemblez chaque package avec son ensemble assigné de trois options technologiques.
* Découpez l'étiquette correspondante (depuis la liste des packages avec codes QR).
* Collez l'étiquette avec le numéro de package et le code QR sur le package avant de le distribuer aux participants.

Chaque package d'essai doit contenir les quatre éléments suivants :

1. Un code QR généré pour chaque package, qui sera utilisé comme identifiant unique pour suivre toutes les informations collectées au cours de l'essai. Il est important d'informer les agriculteurs de conserver ce code pendant toute la durée de l'essai. [En savoir plus sur la génération de codes QR ici.](/design/climmob-setup#technology-randomization)

2. Trois sachets contenant des quantités égales des options technologiques (par exemple, semences, engrais) ou des instructions sur la façon d'appliquer les options technologiques alternatives (par exemple, systèmes de travail du sol), selon la randomisation générée par ClimMob.

3. Une fiche d'observation sur laquelle les testeurs noteront leurs observations en champ. [En savoir plus sur les fiches d'observation ici.](/design/climmob-setup#prepare-observation-cards)

4. Une brochure expliquant l'ensemble du processus à l'agriculteur. [Des illustrations et d'autres supports de communication avec les agriculteurs sont disponibles ici.](/resources/resources#support_material)

### Attribuer et distribuer les packages

Une fois que vous avez préparé les packages avec les différentes options technologiques [(voir comment procéder ici)](/distribution/packages#prepare-the-trial-packages), il est temps de se rendre sur le terrain pour les distribuer et enregistrer chaque participant avec son package d'essai correspondant.

Comment faire :

Il existe différentes façons de procéder : vous pouvez organiser une réunion avec tous les participants ou les visiter individuellement à leur emplacement.

**Avec ODK Collect**

Au minimum, ces données de base sont requises :
* Code QR du package d'essai
* Nom du testeur (agriculteur participant)

Le code du package d'essai utilise un code QR généré par ClimMob comme identifiant unique du package tout au long de l'essai. Le code QR est généré une fois que les technologies sont définies et que la randomisation est configurée. Le responsable du projet imprime les codes (disponibles dans la section Téléchargements) et les colle sur chaque package. **Remarque : les agriculteurs doivent conserver le code (QR) de leur package pendant toute la durée du projet.**

1. Ouvrez ODK Collect et récupérez le formulaire d'enregistrement vierge.

2. Remplissez le formulaire avec les données du participant. La première étape consiste à scanner le code QR attaché au package contenant les trois options technologiques que le participant reçoit. Cela lie le package à son profil individuel.

3. Une fois les formulaires complétés, envoyez-les au serveur.

**Papier** (NON RECOMMANDÉ, car cela prend beaucoup plus de temps et est plus susceptible d'engendrer des erreurs) :

1. Vous pouvez également enregistrer les participants à l'aide de formulaires papier. Ceux-ci sont disponibles sous Téléchargements → Formulaire d'enregistrement imprimable.

2. Saisissez les données dans un fichier Excel. Dans le menu principal (côté gauche), cliquez sur Télécharger les données (bouton vert) → Créer un modèle. Le modèle sera généré et disponible dans Téléchargements → Modèle Excel pour le téléchargement des données du formulaire d'enregistrement.

3. Une fois le modèle rempli, retournez au menu principal, cliquez sur Télécharger les données (bouton vert, côté gauche) et téléchargez le document Excel.

Vérifier, modifier et finaliser l'enregistrement :

* Cliquez sur le bouton vert Afficher les données pour consulter les données soumises et les modifier si nécessaire.
* Cliquez sur le bouton rouge Finaliser l'enregistrement une fois que vous avez enregistré tous les participants.

⚠️ Veuillez noter : Cette étape est irréversible, donc ne procédez que lorsque vous êtes certain(e) que l'enregistrement est complet.
