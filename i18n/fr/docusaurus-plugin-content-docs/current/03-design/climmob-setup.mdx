## Configurer un nouveau projet ClimMob 

Vous devriez déjà avoir créé un compte utilisateur dans ClimMob [(voir les instructions pour le faire ici).](/preparation/introduce-climmob#create-a-climmob-account) Pour commencer à travailler avec ClimMob, votre première étape est de créer un nouveau projet. Vous pouvez le faire de deux manières : soit en allant dans la section Aperçu du projet et en cliquant sur Créer un nouveau projet, soit en naviguant vers Tous les projets et en sélectionnant Ajouter un nouveau projet. Dans les deux cas, il vous sera demandé de remplir un court formulaire avec les principaux détails du projet. Une fois créé, vous pouvez toujours revenir plus tard pour mettre à jour ou ajuster les paramètres du projet.

Pour configurer un profil pour votre projet tricot, les champs à remplir sont :

1) Informations générales

* Nom du projet : Nom unique et plus descriptif pour le projet. Nous recommandons d'inclure la technologie, l'année ou la période, et le lieu, pour distinguer le projet des autres lorsque vous gérez plusieurs projets. Par exemple : Bean_Honduras_2019_season1  

* ID du projet : Identifiant court et unique du projet. Par exemple, vos initiales et l'année du projet : JV19.
* Description : Ajoutez plus de détails sur le projet. 
* Mots-clés : Pour rendre votre projet consultable par d'autres utilisateurs, entrez jusqu'à X mots-clés qui définissent votre projet. Exemples : « bean », « Honduras ».
* Coordinateur de l'essai : Votre nom complet, en commençant par votre prénom, tous les noms séparés par un espace. Par défaut, il est déjà rempli avec vos données. Modifiez-le si le coordinateur de l'essai est quelqu'un d'autre.  
* Adresse e-mail : Votre adresse e-mail. 
* Affiliation : Sélectionnez-en une ou créez une nouvelle affiliation si l'une des options correspond à votre organisation.  

2) Informations géographiques

* Sélectionnez le pays où le projet aura lieu

3) Participants

*	Nombre de participants : Indiquez combien de participants rejoindront ce projet. Par exemple : 200. Si vous ne connaissez pas encore le nombre exact, il vaut mieux choisir un nombre trop élevé que trop faible (mais restons raisonnables, sinon ClimMob effectuera beaucoup de calculs inutiles par la suite).

4) Étiquettes des options technologiques

* Nombre d'options technologiques que chaque participant compare : Par défaut, ce nombre est fixé à « 3 » et ne peut pas être modifié. C'est un rappel que dans un projet tricot, chaque participant recevra 3 options technologiques à comparer.
* Nom donné aux 3 éléments que chaque participant compare : par défaut, les noms sont « Option A, Option B et Option C », mais le coordinateur de l'essai peut décider de les remplacer par autre chose à laquelle les participants peuvent mieux s'identifier, comme des chiffres, des couleurs ou des formes.

5) Type de projet

* Vous pouvez indiquer si le projet est un projet de formation. Cela signifie que le projet a été créé à des fins éducatives — comme la pratique, les démonstrations ou les travaux de cours — et non destiné à une collecte de données réelle sur le terrain.
* Il existe trois options pour le site expérimental : essais en exploitation agricole, à domicile ou dans un espace public (par exemple, un marché). Selon le site expérimental sélectionné, vous devrez choisir entre différentes unités d'analyse et objectifs correspondants (voir les exemples dans l'encadré ci-dessous).
*	Voulez-vous créer votre projet à partir d'un modèle SOP ? Sélectionnez cette option si elle s'applique à votre projet. [En savoir plus sur les SOPs ici.](/design/sops#introduction)
*	Enfin, vous pouvez sélectionner jusqu'à quatre langues dans lesquelles les formulaires destinés aux participants seront fournis, permettant ainsi une collecte de données multilingue selon les besoins.

### Sélectionner les options technologiques

Dans cette section, vous pouvez spécifier les options technologiques que vous souhaitez comparer dans votre expérience tricot. Par exemple, si vous souhaitez tester des variétés de haricots, vous ajouteriez ici les noms des variétés de haricots à tester. Si vous souhaitez tester différents régimes de fertilisation, vous ajouteriez les noms de ces régimes.

Comment faire :

1.	Dans la section aperçu du projet, cliquez sur le bouton vert Sélectionner les options technologiques.

2.	Vous accéderez à la liste des technologies disponibles sur la plateforme. Si la technologie qui vous intéresse s'y trouve, cliquez simplement dessus et accédez aux différentes options (par exemple, les variétés).

3.	Si la technologie qui vous intéresse n'est pas disponible, cliquez sur + ajouter une nouvelle technologie. Cette action vous redirigera vers la bibliothèque, où vous pourrez créer de nouvelles technologies.

### Préparer le formulaire de collecte de données

Dans cette section, vous définissez les différents moments de collecte de données pour l'évaluation en exploitation que les participants effectueront. À chaque moment, des questions spécifiques seront posées pour recueillir des observations. Il est important de décider :

*	Quels caractères seront évalués dans les options technologiques sélectionnées ?
*	Quand chaque caractère sera-t-il évalué au cours du cycle de plantation ?

Une fois configurés, ces formulaires de collecte de données guideront les agents de terrain et les participants pendant le processus d'évaluation.

Comment faire :

1.	Dans la section de définition du projet, cliquez sur Préparer la collecte de données. Vous pouvez y ajouter les différents moments de collecte de données tout au long du cycle de plantation.

2.	Après avoir ajouté les moments de collecte de données, accédez au panneau de droite (Moments de collecte de données actifs) et cliquez sur Afficher pour les visualiser.

3.	Pour chaque moment de collecte de données, faites glisser les questions souhaitées depuis le panneau de gauche (questions disponibles dans la bibliothèque) vers le panneau central (formulaire d'évaluation). Un aperçu des questions sélectionnées apparaîtra dans le panneau de droite (aperçu) — faites défiler vers le bas pour voir toutes les questions.

4.	Si la question dont vous avez besoin ne se trouve pas dans la bibliothèque, cliquez sur Ajouter une nouvelle question et créez-la dans la section la plus pertinente.

### Randomisation des technologies

Après avoir configuré vos moments de collecte de données et leurs questions correspondantes, l'étape suivante consiste à créer des packages de test par randomisation des technologies. Ce processus garantit que chaque participant reçoit un ensemble équilibré d'options technologiques à évaluer.

Comment faire :

1. Dans la section aperçu du projet (côté droit de l'écran), cliquez sur Générer des packages avec des options technologiques pour ouvrir le formulaire d'inscription des participants.

2. Définir les combinaisons :

* Choisissez d'inclure toutes les options technologiques ou seulement une sélection.
* Définissez combien de packages contenant chaque option technologique seront générés.
* Par défaut, toutes les options technologiques sont incluses et le même nombre de packages est créé pour chacune.

**AVERTISSEMENT** Si vous modifiez le nombre de packages pour une technologie, vous devez équilibrer le total en ajoutant ou en soustrayant des packages aux autres pour garantir le même nombre global de packages.

3. Vérifiez les packages et confirmez. Si la liste des packages n'est pas confirmée, elle sera perdue et vous devrez répéter la randomisation.

4. Une fois confirmés, les documents de randomisation sont disponibles dans la section Téléchargements :

* Liste des packages avec codes QR pour le formulaire d'inscription → nécessaire pour préparer les packages de test.
* Liste avec les packages d'essai randomisés (Excel) → indique les combinaisons de technologies attribuées à chaque package. Ce fichier est utile lors de la préparation des packages de test. Ne modifiez pas ce fichier.
