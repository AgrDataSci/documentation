## Introduction

La documentation d'essai est une étape clé pour s'assurer que les enregistrements de votre projet sont complets et prêts pour l'analyse. Cette fonctionnalité de ClimMob vous permet de suivre tous les aspects essentiels de votre essai à travers un ensemble de formulaires.

Vous pouvez commencer à remplir les formulaires à n'importe quel moment pendant le projet, dès sa création. Certains formulaires sont généralement complétés au début, tandis que d'autres sont remplis à la fin. **Remarque : tous les formulaires doivent être complétés avant de passer à l'étape d'Analyse des données et de télécharger les rapports.**

Comment remplir les formulaires :

Pour offrir un maximum de flexibilité tout en maintenant des données standardisées, les formulaires incluent les fonctionnalités suivantes :

*	Options à sélection multiple : La plupart des champs vous permettent de choisir plusieurs réponses. Repérez l'indication « Sélectionnez tout ce qui s'applique » pour documenter les cas où plusieurs méthodes ou critères ont été utilisés (par exemple, combiner différents lieux de recrutement).
*	La catégorie « Autre » : Si votre méthode ou ressource spécifique ne figure pas dans le menu déroulant, sélectionnez « Autre ». Cela ouvrira une zone de texte dédiée pour vous permettre de fournir une description personnalisée, garantissant ainsi que chaque détail de vos opérations de terrain est capturé.
*	Non applicable : Si une question spécifique ne s'applique pas à la portée de votre projet, vous pouvez sélectionner l'option « Non applicable » pour continuer.

## Structure

La section Documentation d'essai comprend les huit formulaires suivants :

### 1.	Contributeurs

Documentez les organisations, chercheurs ou institutions impliqués dans le projet, y compris leurs rôles et responsabilités. Cela permet de reconnaître les contributions et d'assurer la transparence.

**Remarque :** Ce formulaire est exclusivement destiné aux contributeurs techniques et opérationnels. Les institutions de financement ou les donateurs ne doivent pas être répertoriés ici, car ils disposent d'une section dédiée dans la documentation.

Lors de l'ajout d'un collaborateur, vous devez fournir les informations suivantes :

*	Nom du collaborateur : Vous pouvez rechercher des utilisateurs ClimMob existants. Si la personne a un profil, son nom apparaîtra pour la sélection. Si elle n'est pas dans le système, vous pouvez saisir son nom complet, et le système l'étiquettera comme « contributeur externe ».
*	Secteur : Précisez le secteur professionnel ou industriel auquel appartient le collaborateur.
*	Organisation : Commencez à saisir l'affiliation. Si elle figure déjà dans notre base de données mondiale, sélectionnez-la dans la liste. S'il s'agit d'une nouvelle institution, entrez le nom complet, et ClimMob ajoutera une étiquette « -nouvelle affiliation ».
*	Rôle : Vous pouvez sélectionner plusieurs rôles pour un même contributeur. Ce champ suit le schéma de métadonnées DataCite, garantissant que les rôles sont standardisés pour la citation de données à l'échelle mondiale.
*	Activités : Précisez les tâches spécifiques effectuées par le contributeur. Cette sélection est basée sur la CRediT (Contributor Roles Taxonomy), qui permet un niveau élevé de granularité dans l'identification des contributions spécifiques (par exemple, Curation des données, Investigation, Logiciel, etc.).

### 2.	Bailleurs de fonds

Cette nouvelle section dédiée vous permet d'enregistrer le soutien financier derrière votre essai. Le maintien d'enregistrements de financement précis est crucial pour la transparence, la conformité aux exigences des donateurs et les rapports institutionnels.

Si votre projet a reçu un soutien financier externe, vous pouvez documenter plusieurs sources en fournissant les informations suivantes pour chacune :

*	Nom du bailleur de fonds : Recherchez le nom du donateur ou de l'institution fournissant les fonds. Le système comprend une liste préremplie d'organisations de financement mondiales pour assurer la cohérence.
*	Titre de la subvention : Entrez le nom officiel de la subvention ou du projet tel que spécifié dans l'accord de financement.
*	Numéro de subvention : Fournissez le code d'identification unique ou le numéro de référence attribué par le bailleur de fonds à cette subvention spécifique.
**Remarque :** Si votre recherche est soutenue par plusieurs donateurs, utilisez le bouton « + Ajouter un autre » pour créer une entrée distincte pour chaque source de financement.

### 3.	Conception expérimentale

Ce formulaire consolide la structure technique de l'essai avec son alignement stratégique. Il vous permet de documenter tout, depuis la disposition physique des parcelles jusqu'aux marchés cibles spécifiques que la recherche vise à adresser.

Dans ce formulaire, vous devrez préciser :

*	Taille de la parcelle : Indiquez si une taille de parcelle standard a été utilisée dans l'essai. Si c'est le cas, fournissez la superficie en mètres carrés (m2).
*	Remarques sur la conception : Un espace pour documenter toute observation ou note spécifique concernant la conception physique de la parcelle.
*	Conception expérimentale : Sélectionnez les conceptions statistiques ou méthodologiques appliquées dans l'essai (par exemple, blocs incomplets, conceptions randomisées, etc.).
*	Caractéristiques spéciales : Décrivez tout élément unique, comme des méthodologies innovantes, l'utilisation de technologies avancées ou des conditions environnementales spécifiques qui ont influencé l'exécution de l'essai.
*	Segments de marché : Identifiez les segments de marché spécifiques associés au projet. Ces options sont synchronisées avec la Plateforme mondiale d'intelligence de marché (GloMIP) (https://glomip.cgiar.org/).
*	ID de profil de produit cible (TPP) : Associez le projet à des ID TPP spécifiques de la plateforme GloMIP. Cela garantit que les résultats de l'essai sont directement liés aux objectifs d'amélioration génétique mondiaux standardisés et aux exigences de produits.

### 4.	Génotypes

Cette section fournit un profil technique détaillé des technologies testées. Pour gagner du temps et assurer la cohérence, ClimMob liste automatiquement les génotypes que vous avez inclus lors de la configuration du projet.

Votre tâche dans ce formulaire est de passer en revue la liste générée automatiquement et de compléter les champs descriptifs. Bien que ces informations soient utilisées à des fins de documentation et de métadonnées — et n'affectent pas les résultats statistiques de l'essai — elles sont essentielles pour l'interprétation à long terme des données.

Pour chaque génotype, vous devez fournir :

*	Nom du génotype : Le nom original tel qu'enregistré dans le projet.
*	Nom final du génotype : Utilisez ce champ si vous devez standardiser le nom pour le rapport final ou la publication.
*	Type d'entrée : Classifiez le matériel (par exemple, témoin historique, témoin agriculteur, témoin commercial, entrée d'évaluation, candidat à la libération, etc.).

Tableau 1. Options de type d'entrée utilisées dans les essais en milieu paysan ou d'amélioration génétique et leurs descriptions.

| Option de type d'entrée | Description |
|-------------------------|-------------|
| Témoin historique | Une variété qui était largement utilisée dans le passé mais qui n'est plus le premier choix. Utilisée pour mesurer le gain génétique au fil du temps. |
| Témoin agriculteur | La variété locale ou le matériel actuellement géré et préféré par les agriculteurs dans la zone d'essai. Essentiel pour calculer les « taux de succès ». |
| Témoin commercial | Une variété de premier plan actuellement disponible sur le marché local. Utilisée pour comparer la performance des nouveaux matériaux aux meilleures options commerciales actuelles. |
| Témoin comparatif | Une entrée spécifique utilisée comme référence pour certains traits (par exemple, une variété connue tolérante à la sécheresse utilisée pour comparer de nouvelles lignées tolérantes à la sécheresse). |
| Entrée d'évaluation | Le matériel expérimental principal, la lignée ou la technologie testée dans l'essai pour une adoption potentielle ou un développement génétique ultérieur. |
| Candidat à la libération | Une lignée avancée qui a montré des performances supérieures et se trouve dans les dernières étapes du processus réglementaire officiel pour la libération commerciale. |
| Candidat de remplacement | Un matériel spécifique destiné à remplacer une variété existante devenue susceptible aux ravageurs, aux maladies ou à l'évolution des conditions climatiques. |


*	Année de libération : Le cas échéant, l'année à laquelle la variété a été officiellement libérée.
*	Année de croisement : L'année à laquelle le croisement spécifique a été effectué (pour les lignées d'amélioration génétique).
*	Origine : La source géographique ou institutionnelle du matériel génétique.
*	Traits cibles : Précisez les caractéristiques clés évaluées (par exemple, tolérance à la sécheresse, résistance aux ravageurs, rendement).

Tableau 2. Options de traits cibles utilisées pour classer le principal objectif d'évaluation dans les essais en milieu paysan ou d'amélioration génétique.

| Option de trait cible | Description |
|-----------------------|-------------|
| Tolérance à la sécheresse | La capacité du génotype à maintenir sa croissance et sa productivité pendant les périodes de faible disponibilité en eau ou de stress hydrique significatif. |
| Résistance aux ravageurs | La capacité du matériel à résister ou à minimiser les dommages causés par les insectes ou autres ravageurs animaux. |
| Résistance aux maladies | La capacité de la plante à prévenir ou à récupérer des infections causées par des agents pathogènes tels que les champignons, les bactéries ou les virus. |
| Qualité du produit | Caractéristiques liées à l'utilisation finale de la culture, notamment la teneur en éléments nutritifs, le goût, la texture, l'apparence ou les qualités de transformation industrielle. |
| Rendement | La quantité totale de produit récolté (par exemple, grain, tubercules, fruits) par unité de surface, représentant la productivité globale. |
| Autre | Utilisez cette option pour des traits spécifiques non couverts ci-dessus, tels que la tolérance au froid, la précocité ou la résistance à la salinité du sol. (Précisez dans la colonne Autres traits). |

*	Remarques : Un champ de texte libre pour toute note technique supplémentaire ou observation spécifique à ce génotype.
* Lien vers des références externes : Liens vers des sources externes fournissant des informations supplémentaires sur le génotype.

### 5.	Recrutement des participants

Comprendre comment les participants sont sélectionnés et impliqués est fondamental pour la validité statistique et l'intégrité éthique d'un essai tricot. Ce formulaire utilise des champs à sélection multiple pour documenter avec précision le processus d'échantillonnage et de recrutement.

Complétez les sections suivantes en sélectionnant toutes les options qui s'appliquent à votre projet :

*	Calcul de la taille de l'échantillon : Sélectionnez les méthodes utilisées pour déterminer le nombre de participants. Cela assure la transparence sur la question de savoir si l'essai dispose d'une puissance statistique suffisante.

Tableau 3. Options de calcul de la taille de l'échantillon utilisées pour documenter comment le nombre de participants a été déterminé dans les essais en milieu paysan ou d'amélioration génétique.

| Options de calcul de la taille de l'échantillon | Description |
|-------------------------------------------------|-------------|
| Calculateur de taille d'échantillon ClimMob | La taille de l'échantillon a été déterminée à l'aide de l'outil calculateur intégré ClimMob/Tricot. |
| Analyse de la puissance statistique | Détermination du nombre minimum de participants nécessaires pour s'assurer que l'essai dispose d'une force statistique suffisante pour détecter de manière fiable des différences significatives entre les génotypes. |
| Modèle Plackett-Luce | Spécifiquement estimé pour les essais utilisant le modèle Plackett-Luce pour les comparaisons de classement ou de choix. |
| Basé sur la disponibilité des semences | Le nombre de participants était limité par la quantité réelle de semences ou d'unités technologiques disponibles. |
| Nombre cible convenu avec les donateurs/projet | La taille était dictée par les objectifs du projet ou des accords formels avec les donateurs plutôt que par des statistiques. |
| Directives ou méthodes publiées | Déterminé en suivant la littérature scientifique établie ou les directives institutionnelles standardisées. |

*	Critères de sélection : Documentez les attributs ou exigences spécifiques utilisés pour choisir les participants (par exemple, le genre, l'expertise agricole ou les conditions socioéconomiques).
