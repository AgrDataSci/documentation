# Partager votre projet dans ClimMob

> Sofía Acuña, Marilyn Manrow, Brandon Madriz

ClimMob vous permet de collaborer en partageant votre projet avec d'autres utilisateurs. Lorsque vous invitez quelqu'un, vous devez lui attribuer un rôle qui définit le niveau d'accès dont il disposera :

*	Owner – Attribué automatiquement à la personne qui a créé le projet. Les propriétaires ne peuvent pas être modifiés.
*	Admin – Contrôle total du projet, y compris la permission de le partager avec d'autres.
*	Editor – Peut modifier n'importe quelle section du projet mais ne peut pas le partager avec de nouveaux utilisateurs.
*	Member – Accès en lecture seule. Les membres peuvent consulter toutes les informations mais ne peuvent pas effectuer de modifications.

Comment partager un projet avec d'autres utilisateurs :

1.	Dans ClimMob, ouvrez la vue d'ensemble du projet et accédez à la section Share project.

2.	Saisissez l'adresse e-mail de l'utilisateur que vous souhaitez inviter.

3.	Sélectionnez le rôle (Admin, Editor ou Member) qui correspond le mieux à son niveau de participation.

4.	Confirmez pour partager le projet. L'utilisateur invité aura désormais accès selon le rôle que vous lui avez attribué.
