# Clôture d'un projet

>Sofía Acuña, Marilyn Manrow, Brandon Madriz

Une fois que vous avez terminé la collecte de données et atteint les objectifs de votre essai, l'étape suivante consiste à clôturer votre projet. Cette action établit la transition d'un espace de travail actif vers un enregistrement fermé, garantissant que vos données restent cohérentes et prêtes pour l'analyse, la production de rapports ou une utilisation à long terme.

La clôture d'un projet est le processus de conversion d'un espace de travail actif en un enregistrement permanent en lecture seule. Bien qu'un projet puisse être clôturé à tout moment, il est recommandé de ne le faire qu'une fois tous les objectifs de recherche atteints.

## Quand devriez-vous clôturer un projet ?

La clôture d'un projet est une étape clé. Il est recommandé de procéder uniquement lorsque :

* Toutes les données ont été collectées et vérifiées.
* Les détails du projet et la documentation de l'essai sont complets.

**1. Permissions des utilisateurs**

Seul le propriétaire du projet a l'autorité pour clôturer un projet. Les collaborateurs disposant d'un accès partagé ne peuvent pas effectuer cette action.

**2. Liste de vérification avant la clôture**

Avant de clôturer, vérifiez les statuts suivants :

* Complétude des données : Confirmez que toutes les saisies de données sont exactes et qu'aucune autre entrée n'est attendue.
* Profil du projet : Passez en revue les détails clés du projet (par exemple, le nom, la description et les paramètres de l'essai), car ceux-ci seront verrouillés.
* Documentation de l'essai : Cette étape doit être marquée comme Complétée. Bien qu'elle ne soit pas obligatoire pour clôturer le projet, elle est nécessaire pour activer le module d'analyse.

**3. Le processus de confirmation**

La sélection de « Clôturer le projet » déclenche un écran de confirmation avec des alertes importantes :

* Verrouillage permanent des données : Toutes les saisies de données, les métadonnées et les paramètres du projet seront verrouillés et ne pourront pas être modifiés.
* Exigence du module d'analyse :
  + Si la documentation de l'essai est incomplète, vous serez averti que le module d'analyse ne sera pas disponible après la clôture du projet.
  + Si les données collectées sont insuffisantes, le système vous alertera que le module d'analyse pourrait ne pas générer de résultats.
* Avertissement concernant les conflits non résolus : Si des soumissions comportent des conflits, vous serez informé que l'analyse ne peut pas être générée et que ces conflits ne pourront pas être résolus une fois le projet clôturé.

**4. Après la clôture : Mode Lecture Seule**

Après confirmation, le projet passe en Mode Lecture Seule afin de garantir l'intégrité des enregistrements :

* Accessibilité : Toutes les informations du projet, les résultats et les métadonnées restent disponibles pour consultation.
* Disponibilité de l'analyse : Si la documentation de l'essai est complétée et que suffisamment de soumissions valides sont présentes, le module d'analyse reste disponible après la clôture du projet.
* Restrictions : La modification est désactivée. Toute tentative de modification du projet entraînera un message *Accès Restreint (403)*.
* Notification : Un e-mail est envoyé au propriétaire du projet et aux administrateurs de 1000FARMS les informant que le projet a été clôturé.
