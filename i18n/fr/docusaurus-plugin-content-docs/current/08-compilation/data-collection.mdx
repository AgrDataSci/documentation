# Collecte de données

> Sofía Acuña, Marilyn Manrow, Brandon Madriz, Kauê de Sousa

Une fois que les agriculteurs ont commencé leurs essais à la ferme, l'étape suivante consiste à collecter les données générées lors des différents moments de collecte. Pour chaque moment, ClimMob génère un formulaire spécifique avec des questions adaptées [(cliquez ici pour accéder à l'étape « Préparer le formulaire de collecte de données » dans ClimMob)](/design/climmob-setup#prepare-data-collection-form). Les données peuvent être collectées à l'aide d'ODK Collect (recommandé) ou, alternativement, en téléchargeant un fichier Excel sur la plateforme ClimMob.

**Utilisation d'ODK Collect (recommandé)**

1. Chaque agent de terrain ouvre ODK Collect sur son téléphone.

2. Appuyez sur les trois points (en haut à droite) → Obtenir un formulaire vierge → sélectionnez le formulaire de collecte de données.

3. Pour le premier moment de collecte de données :

* Choisissez Remplir un formulaire vierge
* Sélectionnez le participant
* Saisissez les données
* Envoyez le formulaire finalisé

4. Sur la plateforme ClimMob, l'administrateur du projet doit :

* Vérifier les données collectées et les corriger si nécessaire (depuis le tableau de bord principal, cliquez sur Afficher les données à droite et sélectionnez les paramètres à examiner).
* Une fois vérifiées, allez dans le menu principal, terminez la première collecte de données et commencez l'évaluation suivante.

5. Répétez ce processus jusqu'à ce que tous les points de collecte de données soient complétés.

Actions dans ODK Collect :

Annuler le formulaire : Supprime définitivement le formulaire. Aucune donnée supplémentaire ne peut être collectée, et toutes les données existantes seront également supprimées.

**Utilisation d'Excel (non recommandé)**

1. Dans le tableau de bord ClimMob, accédez au menu principal (côté gauche) et cliquez sur Télécharger des données (bouton vert).

2. Cliquez sur Créer un modèle. Le modèle Excel sera généré et enregistré dans vos Téléchargements sous le nom Modèle Excel pour le téléchargement des données du formulaire d'évaluation.

3. Remplissez le modèle avec les données collectées.

4. Retournez dans le menu principal ClimMob → Télécharger des données (bouton vert) → téléchargez le fichier Excel complété.

**Soumettre des données depuis un navigateur**

Pour remplir des formulaires en ligne pris en charge par Enketo, les agents de terrain (enquêteurs) doivent se connecter à l'aide de leurs identifiants (nom d'utilisateur et mot de passe). Voici une explication rapide sur la façon d'enregistrer un nouvel agent de terrain, qui se connectera ensuite à Enketo pour soumettre des données depuis un navigateur.

(Les étapes suivantes sont accompagnées des captures d'écran correspondantes de ClimMob)

Visitez la section Agents de terrain dans le menu principal :


![](/img/menu.JPG)
---
Remplissez le formulaire avec les identifiants de l'agent de terrain.

![](/img/field_credentials.JPG)

---

Vérifiez que l'agent de terrain a bien été créé dans la liste des agents de terrain enregistrés :

![](/img/registered_field.JPG)

---

Dans la définition du projet, sélectionnez « Assigner des agents de terrain » :

![](/img/assign_menu.JPG)

---

Sélectionnez le ou les agents de terrain :

![](/img/assign.JPG)

---

Cliquez sur le bouton « Ajouter des agents de terrain » et vérifiez que l'utilisateur a bien été assigné au projet.

![](/img/field_project.JPG)

---

Dans le menu principal, accédez au formulaire que vous souhaitez remplir via le navigateur et cliquez sur le bouton « Soumettre des données depuis un navigateur » pour afficher le formulaire :

![](/img/submit.JPG)

---

Le formulaire s'affichera alors et demandera les identifiants de l'agent de terrain qui ont été enregistrés dans la Bibliothèque.

![](/img/credentials.JPG)


---

Une fois les identifiants fournis, le formulaire à remplir s'affichera :

![](/img/form.JPG)

---

Dans le cas du formulaire d'inscription, vous devez remplacer le code QR (utilisé dans ODK Collect) par un code qui suit le modèle : nomdutilisateurproprietaireprojet-numeropaquet-codeprojet~

Par exemple, si le nom d'utilisateur du propriétaire du projet est : ballen, le code du projet : prj01 et que vous assignez le paquet n°30, vous devez écrire comme suit : ballen-30-prj01~

N'oubliez pas de conserver le signe ~ à la fin afin que ClimMob puisse lire le code entier.
