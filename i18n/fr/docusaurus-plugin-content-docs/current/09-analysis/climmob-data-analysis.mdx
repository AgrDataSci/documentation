Une fois toutes les données des participants collectées, il est temps d'analyser les résultats. ClimMob fournit des outils intégrés pour traiter vos données tricot et générer des rapports automatiquement.

## Comment lancer l'analyse dans ClimMob ?

1.	Dans la section de vue d'ensemble du projet ClimMob, allez sur le côté droit de l'écran et cliquez sur **Start analysis**.

2.	Sélectionnez les variables que vous souhaitez analyser.

3.	ClimMob traitera les données et générera un rapport final.

## Rapport final produit par ClimMob

Une fois l'analyse terminée, ClimMob génère automatiquement un rapport final résumant les résultats des essais en champ. Ce rapport est conçu pour aider les gestionnaires de projet et les chercheurs à interpréter les résultats et à prendre des décisions fondées sur des données probantes.

### Comprendre le rapport

Le rapport final comprend généralement :

1. Classement des technologies : performance de chaque technologie telle qu'évaluée par les participants.

2. Comparaison des variables : résultats basés sur les variables sélectionnées lors de l'analyse.

3. Résultats visuels : tableaux et graphiques facilitant l'interprétation des préférences et des performances.

### Accéder au rapport

1.	Allez dans la section **Downloads** de la plateforme ClimMob.

2.	Localisez le fichier généré après votre analyse.

3.	Ouvrez le document pour le consulter et le partager avec votre équipe ou les parties prenantes.
