# Enregistrer les participants

> Sofía Acuña, Marilyn Manrow, Brandon Madriz, Kauê de Sousa

### Préparer le formulaire d'enregistrement des participants dans ClimMob

Dans cette section, vous pouvez ajouter et gérer les questions administratives que les agents de terrain poseront aux participants lors de leur enregistrement au début du projet. Ces questions sont importantes pour deux raisons principales :

*	À des fins administratives : pour conserver un enregistrement clair des personnes participant, de leur lieu de résidence et d'autres informations clés qui aident à organiser et à surveiller l'essai.
*	À des fins d'analyse des données : pour permettre des analyses plus approfondies, par exemple, vérifier si les participants plus jeunes adoptent une technologie plus rapidement, ou si les participantes expriment une préférence pour certaines options.

Une fois que vous avez défini la liste des questions, elles seront disponibles via l'application ODK Collect. Les agents de terrain peuvent alors saisir les informations des participants directement dans l'application lors de l'enregistrement.

Comment faire dans ClimMob :

1.	Dans la section de définition du projet, cliquez sur Préparer le formulaire d'enregistrement des participants.

2.	Faites glisser les questions que vous souhaitez inclure depuis le panneau de gauche (questions disponibles dans la bibliothèque) vers le panneau central (formulaire d'évaluation). Un aperçu des questions sélectionnées apparaîtra dans le panneau de droite (aperçu) — faites défiler vers le bas pour les voir toutes.

3.	Si la question souhaitée n'est pas disponible dans la bibliothèque, cliquez sur Ajouter une nouvelle question et créez-la dans la section la plus pertinente.

4.	La bibliothèque ClimMob comprend déjà une liste de questions couramment utilisées, que vous pouvez facilement ajouter au formulaire d'enregistrement.
