# Assigner des agents de terrain

> Sofía Acuña, Marilyn Manrow, Brandon Madriz, Kauê de Sousa

### Assigner des agents de terrain dans ClimMob

Après avoir [créé un projet dans ClimMob et complété l'aperçu du projet](/design/climmob-setup##create_project), vous pouvez ajouter les agents de terrain qui travailleront sur ce projet particulier. Les agents de terrain sont vos agents de vulgarisation sur le terrain qui communiqueront avec les participants et collecteront ensuite toutes les observations d'essai à l'aide de l'application ODK Collect.

1.	Dans la section Aperçu du projet, cliquez sur Assigner des agents de terrain.

2.	Si les agents de terrain avec lesquels vous souhaitez travailler figurent déjà dans la liste de gauche, sélectionnez simplement ceux avec lesquels vous aimeriez travailler dans ce projet.

3.	Si vous souhaitez ajouter de nouveaux agents de terrain, cliquez sur +ajouter un nouvel agent de terrain. Cela vous redirigera vers la bibliothèque des agents de terrain, où vous pourrez ajouter les informations concernant un nouvel agent de terrain.

*Notez que le mot de passe et le nom d'utilisateur de terrain sont nécessaires pour ODK Collect.
