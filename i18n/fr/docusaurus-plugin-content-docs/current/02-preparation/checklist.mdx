# Liste de contrôle

### Ce tableau peut être utilisé comme liste de contrôle pour planifier une expérience tricot.
<a href={useBaseUrl('/pdfs/tricot_trial_checklist.pdf')} target="_blank" rel="noopener noreferrer">
  Cliquez ici pour ouvrir la liste de contrôle au format PDF pour l'impression
</a>


| ✔ | Étape            | Tâche             | Actions clés                                                                                           | Responsable             |
|---|------------------|------------------|-----------------------------------------------------------------------------------------------------|-------------------------|
| ☐ | **1. Préparation** | Définir la portée     | Identifier les problèmes locaux ; sélectionner les options technologiques ; déterminer les critères d'évaluation ; décider de la zone cible et du nombre d'agriculteurs | Chercheurs + Responsables de mise en œuvre |
| ☐ |                | Préparer les matériaux | Produire des semences/intrants de qualité ; préparer les fiches d'observation, les brochures et les supports de formation             | Chercheurs             |
| ☐ | **2. Conception**  | Créer un projet dans ClimMob | Créer un compte ; configurer le projet en utilisant le SOP ; affecter des agents de terrain ; saisir les options technologiques ; réviser les questions de collecte de données | Responsables de mise en œuvre            |
| ☐ |                | Randomisation et packages | Générer des packages d'essai avec des codes QR ; étiqueter les sacs ; préparer des ensembles équilibrés                              | Responsables de mise en œuvre            |
| ☐ | **3. Recrutement** | Sélection des agriculteurs | Identifier des volontaires (hommes/femmes, âges et rôles différents) ; assurer leur engagement                            | Agents de terrain            |
| ☐ |                | Mobilisation     | Sensibilisation via des réunions, des affiches, le bouche-à-oreille                                                         | Agents de terrain            |
| ☐ | **4. Distribution** | Atelier de formation | Former les agriculteurs à la méthode tricot, à la mise en place des essais et aux fiches d'observation                                    | Responsables de mise en œuvre + Agents de terrain |
| ☐ |                | Distribuer les packages d'essai | Fournir des packages avec codes QR comprenant 3 options, une fiche d'observation et une brochure                              | Agents de terrain            |
| ☐ |                | Enregistrer les agriculteurs | Utiliser ODK Collect pour enregistrer les informations des agriculteurs et le code du package                                             | Agents de terrain            |
| ☐ | **5. Exécution** | Essais à la ferme   | Les agriculteurs plantent/gèrent 3 parcelles côte à côte selon leurs pratiques habituelles                                      | Agriculteurs                 |
| ☐ | **6. Observation** | Évaluations sur le terrain | Les agriculteurs notent le « meilleur » et le « pire » pour chaque critère sur les fiches d'observation                             | Agriculteurs                 |
| ☐ |                | Suivi        | Fournir des rappels/soutien par téléphone/visites ; aider au remplissage des fiches si nécessaire                        | Agents de terrain            |
| ☐ | **7. Compilation** | Collecter les données     | Les agents de terrain rassemblent les fiches d'observation/données ; saisie via ODK Collect ; téléchargement vers ClimMob                  | Agents de terrain            |
| ☐ | **8. Analyse** | Traiter les données     | Utiliser ClimMob pour générer des rapports (classements des technologies, analyse des variables explicatives)                  | Responsables de mise en œuvre            |
| ☐ |                | Résultats          | Produire un rapport d'analyse (chercheurs) + des fiches d'information (agriculteurs)                                          | Responsables de mise en œuvre            |
| ☐ | **9. Retour d'information** | Ateliers finaux  | Partager les résultats globaux ; distribuer les fiches d'information ; faciliter les discussions en groupe d'agriculteurs                     | Responsables de mise en œuvre + Agents de terrain |
| ☐ |                | Formation pratique | Proposer des cours d'agronomie complémentaires (ex. : stockage des semences)                                              | Responsables de mise en œuvre            |
| ☐ | **10. Évaluation** | Évaluer le cycle     | Recueillir les retours des agriculteurs et des agents ; évaluer les indicateurs (taux d'achèvement, ratio hommes/femmes, adoption, participation répétée, diffusion) | Chercheurs + Responsables de mise en œuvre |
| ☐ |                | Planifier le prochain cycle  | Ajuster le pool de technologies (éliminer les mauvaises options, en ajouter de nouvelles) ; élargir la participation des agriculteurs                      | Toutes les parties prenantes        |
