# Cierre de un proyecto

>Sofía Acuña, Marilyn Manrow, Brandon Madriz

Una vez que haya completado la recolección de datos y alcanzado los objetivos de su ensayo, el siguiente paso es cerrar su proyecto. Esta acción establece la transición de un espacio de trabajo activo a un registro cerrado, asegurando que sus datos permanezcan consistentes y listos para análisis, reportes o uso a largo plazo.

Cerrar un proyecto es el proceso de convertir un espacio de trabajo activo en un registro permanente de solo lectura. Si bien un proyecto puede cerrarse en cualquier momento, se recomienda hacerlo únicamente después de que todos los objetivos de investigación se hayan completado.

## ¿Cuándo debería cerrar un proyecto?

Cerrar un proyecto es un hito clave. Se recomienda proceder únicamente cuando:

* Todos los datos han sido recolectados y verificados.
* Los detalles del proyecto y la documentación del ensayo están completos.

**1. Permisos de usuario**

Solo el propietario del proyecto tiene la autoridad para cerrarlo. Los colaboradores con acceso compartido no pueden realizar esta acción.

**2. Lista de verificación previa al cierre**

Antes de cerrar, verifique el siguiente estado:

* Completitud de datos: Confirme que todas las entradas de datos son precisas y que no se esperan más ingresos.
* Perfil del proyecto: Revise los detalles clave del proyecto (p. ej., nombre, descripción y configuración del ensayo), ya que estos quedarán bloqueados.
* Documentación del ensayo: Este paso debe estar marcado como Completado. Si bien no es obligatorio para cerrar el proyecto, es necesario para habilitar el módulo de Análisis.

**3. El proceso de confirmación**

Seleccionar "Cerrar proyecto" activa una pantalla de confirmación con alertas importantes:

* Bloqueo permanente de datos: Todas las entradas de datos, metadatos y configuraciones del proyecto quedarán bloqueadas y no podrán modificarse.
* Requisito del módulo de Análisis:
  + Si la documentación del ensayo está incompleta, se le advertirá que el módulo de Análisis no estará disponible después de cerrar el proyecto.
  + Si no hay suficientes datos recolectados, el sistema le alertará que el módulo de Análisis puede no generar resultados.
* Advertencia de conflictos sin resolver: Si hay envíos con conflictos, se le informará que el análisis no puede generarse y que estos no podrán resolverse después de que el proyecto sea cerrado.

**4. Post-cierre: Modo de solo lectura**

Después de la confirmación, el proyecto entra en Modo de solo lectura para garantizar la integridad de los registros:

* Accesibilidad: Toda la información del proyecto, resultados y metadatos permanecen disponibles para su visualización.
* Disponibilidad del análisis: Si la documentación del ensayo está completa y hay suficientes envíos válidos, el módulo de Análisis permanece disponible después de cerrar el proyecto.
* Restricciones: La edición está deshabilitada. Cualquier intento de modificar el proyecto resultará en un mensaje de *Acceso Restringido (403)*.
* Notificación: Se envía un correo electrónico al propietario del proyecto y a los administradores de 1000FARMS informándoles que el proyecto ha sido cerrado.
