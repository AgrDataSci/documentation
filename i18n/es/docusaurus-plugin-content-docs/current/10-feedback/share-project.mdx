# Comparte tu proyecto en ClimMob

> Sofía Acuña, Marilyn Manrow, Brandon Madriz

ClimMob te permite colaborar compartiendo tu proyecto con otros usuarios. Cuando invitas a alguien, debes asignarle un rol que define el nivel de acceso que tendrá:

*	Owner – Asignado automáticamente a la persona que creó el proyecto. Los propietarios no pueden ser cambiados.
*	Admin – Control total del proyecto, incluido el permiso para compartirlo con otros.
*	Editor – Puede modificar cualquier sección del proyecto, pero no puede compartirlo con nuevos usuarios.
*	Member – Acceso de solo lectura. Los miembros pueden ver toda la información, pero no pueden realizar cambios.

Cómo compartir un proyecto con otros usuarios:

1.	En ClimMob, abre el resumen del proyecto (Project overview) y ve a la sección Compartir proyecto (Share project).

2.	Ingresa el correo electrónico del usuario al que deseas invitar.

3.	Selecciona el rol (Admin, Editor o Member) que mejor se adapte a su nivel de participación.

4.	Confirma para compartir el proyecto. El usuario invitado tendrá acceso de acuerdo con el rol que le asignaste.
