# Análisis avanzado de datos en R

> Kauê de Sousa

Esta sección está destinada a usuarios que desean trabajar directamente con datos tricot en R y explorar enfoques analíticos más avanzados y personalizables. Si bien los análisis estándar pueden realizarse a través de ClimMob o R-Instat, trabajar en R permite un control total sobre el procesamiento de datos, la modelización, la visualización y la reproducibilidad.

El siguiente conjunto de paquetes de R ha sido desarrollado para apoyar diferentes etapas del flujo de trabajo con datos tricot, desde el acceso a los datos hasta la modelización estadística avanzada.

**climMobTools:** Proporciona un cliente API para descargar y gestionar datos directamente desde la plataforma ClimMob, facilitando la construcción de flujos de análisis reproducibles. https://cran.r-project.org/package=ClimMobTools

**gosset:** Ofrece métodos para analizar datos agrícolas experimentales, incluyendo herramientas especialmente adecuadas para datos de clasificación del tipo tricot. Permite la preparación de datos, el ajuste de modelos, la priorización de características, la síntesis de datos y la visualización. https://cran.r-project.org/package=gosset

**climatrends:** Apoya el análisis de tendencias climáticas e indicadores agroclimáticos, que pueden vincularse a datos de ensayos en finca para comprender mejor los factores ambientales que influyen en el desempeño. https://cran.r-project.org/package=climatrends

**chirps:** Proporciona acceso a datos climáticos en cuadrícula de CHIRPS y CHIRTS (precipitación y temperatura), permitiendo la integración de información meteorológica diaria en los análisis tricot. https://cran.r-project.org/package=chirps

**PlackettLuce:** Implementa el modelo de Plackett–Luce en R, que constituye la base estadística para el análisis de datos de clasificación en el enfoque tricot. https://cran.r-project.org/package=PlackettLuce

Se recomiendan especialmente dos estudios de caso introductorios.

[Ejemplo práctico con frijol común para priorización de características y desempeño del cultivo](https://agrdatasci.github.io/gosset/articles/vignette-1-trait-prioritization-and-crop-performance.html)

[Ejemplo práctico con pruebas de consumidores de gari/eba](https://agrdatasci.github.io/gosset/articles/vignette-2-gari-eba-consumer-testing.html)

Estos ejemplos ilustran cómo los datos tricot pueden analizarse en R para conectar las evaluaciones de los agricultores, el desempeño agronómico y las decisiones de mejoramiento dentro de un flujo de trabajo completamente reproducible.
