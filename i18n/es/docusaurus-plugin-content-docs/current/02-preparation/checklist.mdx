# Lista de verificación

### Esta tabla puede usarse como lista de verificación para planificar un experimento tricot.
<a href={useBaseUrl('/pdfs/tricot_trial_checklist.pdf')} target="_blank" rel="noopener noreferrer">
  Haga clic aquí para abrir la lista de verificación en formato PDF para imprimir
</a>


| ✔ | Paso            | Tarea             | Acciones clave                                                                                           | Responsable             |
|---|------------------|-----------------|-----------------------------------------------------------------------------------------------------|-------------------------|
| ☐ | **1. Preparación** | Definir alcance     | Identificar problemas locales; seleccionar opciones tecnológicas; determinar criterios de evaluación; decidir área objetivo y número de agricultores | Investigadores + Implementadores |
| ☐ |                | Preparar materiales | Producir semillas/insumos de calidad; preparar tarjetas de observación, folletos y materiales de capacitación             | Investigadores             |
| ☐ | **2. Diseño**  | Crear proyecto en ClimMob | Registrar cuenta; configurar proyecto usando el SOP; asignar agentes de campo; ingresar opciones tecnológicas; revisar preguntas de recopilación de datos | Implementadores            |
| ☐ |                | Aleatorización y paquetes | Generar paquetes de ensayo con códigos QR; etiquetar bolsas; preparar conjuntos balanceados                              | Implementadores            |
| ☐ | **3. Reclutamiento** | Selección de agricultores | Identificar voluntarios (hombres/mujeres, diferentes edades y roles); asegurar compromiso                            | Agentes de campo            |
| ☐ |                | Movilización     | Difusión mediante reuniones, carteles y boca a boca                                                         | Agentes de campo            |
| ☐ | **4. Distribución** | Taller de capacitación | Capacitar a los agricultores en el método tricot, configuración del ensayo y tarjetas de observación                                    | Implementadores + Agentes de campo |
| ☐ |                | Distribuir paquetes de ensayo | Proporcionar paquetes con código QR con 3 opciones, tarjeta de observación y folleto                              | Agentes de campo            |
| ☐ |                | Registrar agricultores | Usar ODK Collect para registrar los datos del agricultor y el código del paquete                                             | Agentes de campo            |
| ☐ | **5. Ejecución** | Ensayos en campo   | Los agricultores siembran/manejan 3 parcelas una al lado de la otra bajo prácticas normales                                      | Agricultores                 |
| ☐ | **6. Observación** | Evaluaciones de campo | Los agricultores registran el "mejor" y el "peor" para cada criterio en las tarjetas de observación                             | Agricultores                 |
| ☐ |                | Seguimiento        | Proporcionar recordatorios/apoyo mediante llamadas/visitas; ayudar con el llenado de tarjetas si es necesario                        | Agentes de campo            |
| ☐ | **7. Compilación** | Recopilar datos     | Los agentes de campo recogen tarjetas de observación/datos; ingresan mediante ODK Collect; cargan a ClimMob                  | Agentes de campo            |
| ☐ | **8. Análisis** | Procesar datos     | Usar ClimMob para generar informes (clasificación de tecnologías, análisis de variables explicativas)                  | Implementadores            |
| ☐ |                | Resultados          | Producir informe de análisis (investigadores) + hojas informativas (agricultores)                                          | Implementadores            |
| ☐ | **9. Retroalimentación** | Talleres finales  | Compartir resultados generales; distribuir hojas informativas; facilitar discusiones grupales de agricultores                     | Implementadores + Agentes de campo |
| ☐ |                | Capacitación práctica | Brindar lecciones adicionales de agronomía (p. ej., almacenamiento de semillas)                                              | Implementadores            |
| ☐ | **10. Evaluación** | Evaluar ciclo     | Recopilar retroalimentación de agricultores y agentes; evaluar indicadores (tasa de finalización, proporción de género, adopción, participación repetida, difusión) | Investigadores + Implementadores |
| ☐ |                | Planificar el siguiente ciclo  | Ajustar el conjunto de tecnologías (eliminar opciones deficientes, agregar nuevas); ampliar la participación de agricultores                      | Todas las partes interesadas        |
