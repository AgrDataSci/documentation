## Configuración de un nuevo proyecto en ClimMob

Ya deberías haber creado una cuenta de usuario en ClimMob [(consulta las instrucciones sobre cómo hacerlo aquí).](/preparation/introduce-climmob#create-a-climmob-account) Para comenzar a trabajar con ClimMob, el primer paso es crear un nuevo proyecto. Puedes hacerlo de dos maneras: ya sea yendo a la sección Resumen del proyecto y haciendo clic en Crear un nuevo proyecto, o navegando a Todos los proyectos y seleccionando Agregar nuevo proyecto. En ambos casos, se te pedirá que completes un breve formulario con los detalles principales del proyecto. Una vez creado, siempre puedes volver más tarde para actualizar o ajustar la configuración del proyecto.

Para configurar un perfil para tu proyecto tricot, los campos a completar son:

1) Información general

* Nombre del proyecto: Nombre único y más descriptivo para el proyecto. Recomendamos incluir la tecnología, el año o período, y la ubicación, para distinguir el proyecto de otros cuando administras múltiples proyectos. Por ejemplo: Frijol_Honduras_2019_temporada1

* ID del proyecto: Identificador corto y único del proyecto. Por ejemplo, tus iniciales y el año del proyecto: JV19.
* Descripción: Agrega más detalles sobre el proyecto.
* Palabras clave: Para hacer tu proyecto visible para otros usuarios, ingresa hasta X palabras clave que definan tu proyecto. Ejemplos: "frijol", "Honduras".
* Coordinador del ensayo: Tu nombre completo, comenzando con tu primer nombre, todos los nombres separados por un espacio. Por defecto, ya está completado con tus datos. Cámbialo si el coordinador del ensayo es otra persona.
* Dirección de correo electrónico: Tu dirección de correo electrónico.
* Afiliación: Selecciona una o crea una nueva afiliación, si alguna de las opciones aplica a tu organización.

2) Información geográfica

* Selecciona el país donde se llevará a cabo el proyecto.

3) Participantes

* Número de participantes: Ingresa cuántos participantes se unirán a este proyecto. Por ejemplo: 200. Si aún no conoces el número exacto, es mejor elegir un número demasiado alto que demasiado bajo (pero aún razonable, ya que de lo contrario ClimMob realizará muchos cálculos innecesarios más adelante).

4) Etiquetas de las opciones tecnológicas

* Número de opciones tecnológicas que cada participante compara: Por defecto, está configurado en '3' y no se puede cambiar. Es un recordatorio de que en un proyecto tricot, cada participante recibirá 3 opciones tecnológicas para comparar.
* Nombre dado a los 3 elementos que cada participante compara: por defecto los nombres son "Opción A, Opción B y Opción C", pero el coordinador del ensayo podría decidir cambiarlos por algo con lo que los participantes puedan identificarse mejor, como números, colores o formas.

5) Tipo de proyecto

* Puedes indicar si el proyecto es un proyecto de capacitación. Esto significa que el proyecto fue creado con fines educativos —como práctica, demostraciones o trabajo académico— y no está destinado a la recopilación real de datos en el campo.
* Hay tres opciones para el sitio experimental: prueba en campo, hogar o espacio público (por ejemplo, mercado). Dependiendo del sitio experimental seleccionado, deberás elegir entre diferentes unidades de análisis y objetivos correspondientes (consulta los ejemplos en el cuadro a continuación).
* ¿Deseas crear tu proyecto a partir de una plantilla SOP? Selecciona si aplica a tu proyecto. [Lee más sobre los SOPs aquí.](/design/sops#introduction)
* Finalmente, puedes seleccionar hasta cuatro idiomas en los que se proporcionarán los formularios para participantes, lo que permite la recopilación de datos en múltiples idiomas según sea necesario.

### Seleccionar opciones tecnológicas

En esta sección, puedes especificar las opciones tecnológicas que deseas comparar en tu experimento tricot. Por ejemplo, si deseas probar variedades de frijol, aquí agregarías los nombres de las variedades de frijol a evaluar. Si deseas probar regímenes de fertilización, agregarías los nombres de los regímenes de fertilización a evaluar.

Cómo hacerlo:

1. En la sección de resumen del proyecto, haz clic en el botón verde Seleccionar opciones tecnológicas.

2. Accederás a la lista de tecnologías disponibles en la plataforma. Si la tecnología que te interesa está allí, simplemente haz clic en ella y accede a las diferentes opciones (por ejemplo, variedades).

3. Si la tecnología que te interesa no está allí, haz clic en + agregar nueva tecnología. Esta acción te redirigirá a la biblioteca, donde puedes crear nuevas tecnologías.

### Preparar el formulario de recopilación de datos

En esta sección, defines los diferentes momentos de recopilación de datos para la evaluación en campo que llevarán a cabo los participantes. En cada momento, se harán preguntas específicas para capturar observaciones. Es importante decidir:

* ¿Qué características se evaluarán en las opciones tecnológicas seleccionadas?
* ¿Cuándo se evaluará cada característica durante el ciclo de siembra?

Una vez configurados, estos formularios de recopilación de datos guiarán a los agentes de campo y a los participantes durante el proceso de evaluación.

Cómo hacerlo:

1. En la sección de definición del proyecto, haz clic en Preparar recopilación de datos. Aquí puedes agregar los diferentes momentos de recopilación de datos a lo largo del ciclo de siembra.

2. Después de agregar los momentos de recopilación de datos, ve al panel derecho (Momentos activos de recopilación de datos) y haz clic en Mostrar para verlos.

3. Para cada momento de recopilación de datos, arrastra las preguntas deseadas desde el panel izquierdo (preguntas disponibles de la biblioteca) hacia el panel central (formulario de evaluación). Una vista previa de las preguntas seleccionadas aparecerá en el panel derecho (vista previa)—desplázate hacia abajo para ver todas las preguntas.

4. Si la pregunta que necesitas no está en la biblioteca, haz clic en Agregar nueva pregunta y créala en la sección más relevante.

### Aleatorización de tecnologías

Después de configurar tus momentos de recopilación de datos y sus preguntas correspondientes, el siguiente paso es crear paquetes de prueba mediante la aleatorización de tecnologías. Este proceso garantiza que cada participante reciba un conjunto equilibrado de opciones tecnológicas para evaluar.

Cómo hacerlo:

1. En la sección de resumen del proyecto (lado derecho de la pantalla), haz clic en Generar paquetes con opciones tecnológicas para abrir el formulario de registro de participantes.

2. Configura las combinaciones:

* Elige si incluir todas las opciones tecnológicas o solo una selección.
* Define cuántos paquetes con cada opción tecnológica se generarán.
* Por defecto, se incluyen todas las opciones tecnológicas y se crea el mismo número de paquetes para cada una.

**ADVERTENCIA** Si cambias el número de paquetes para una tecnología, debes compensar el total agregando o restando en otras para garantizar el mismo número total de paquetes.

3. Revisa los paquetes y confírmalos. Si la lista de paquetes no se confirma, se perderá y deberás repetir la aleatorización.

4. Una vez confirmados, los documentos de aleatorización están disponibles en la sección de Descargas:

* Lista de paquetes con códigos QR para el formulario de registro → necesaria para preparar los paquetes de prueba.
* Lista con paquetes de ensayo aleatorizados (Excel) → muestra las combinaciones de tecnologías asignadas a cada paquete. Este archivo es útil al preparar los paquetes de prueba. No edites este archivo.
