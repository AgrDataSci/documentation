## Introducción

La documentación del ensayo es un paso clave para garantizar que los registros de su proyecto estén completos y listos para el análisis. Esta función de ClimMob le permite llevar un seguimiento de todos los aspectos esenciales de su ensayo a través de un conjunto de formularios.

Puede comenzar a completar los formularios en cualquier momento durante el proyecto, desde su creación. Algunos formularios se completan típicamente al inicio, mientras que otros se completan al final. **Nota: todos los formularios deben estar completos antes de pasar al paso de Análisis de datos y descargar informes.**

Cómo completar los formularios:

Para proporcionar la máxima flexibilidad manteniendo datos estandarizados, los formularios incluyen las siguientes características:

*	Opciones de selección múltiple: La mayoría de los campos le permiten elegir más de una respuesta. Busque la indicación "Seleccione todas las que apliquen" para documentar casos en que se utilizaron múltiples métodos o criterios (por ejemplo, combinar diferentes ubicaciones de reclutamiento).
*	La categoría "Otro": Si su método o recurso específico no aparece en el menú desplegable, seleccione "Otro". Esto abrirá un cuadro de texto dedicado para que proporcione una descripción personalizada, asegurando que cada detalle de sus operaciones de campo quede registrado.
*	No aplicable: Si una pregunta específica no aplica al alcance de su proyecto, puede seleccionar la opción "No aplicable" para continuar.

## Estructura

La sección de Documentación del ensayo incluye los siguientes ocho formularios:

### 1.	Colaboradores

Documente las organizaciones, investigadores o instituciones involucradas en el proyecto, incluyendo sus roles y responsabilidades. Esto ayuda a reconocer las contribuciones y garantiza la transparencia.

**Nota:** Este formulario es exclusivamente para colaboradores técnicos y operativos. Las instituciones financiadoras o donantes no deben incluirse aquí, ya que tienen una sección dedicada en la documentación.

Al agregar un colaborador, debe proporcionar los siguientes detalles:

*	Nombre del colaborador: Puede buscar usuarios existentes de ClimMob. Si la persona tiene un perfil, su nombre aparecerá para su selección. Si no está en el sistema, puede ingresar su nombre completo y el sistema lo etiquetará como un "colaborador externo".
*	Sector: Especifique el sector profesional o industrial al que pertenece el colaborador.
*	Organización: Comience a escribir la afiliación. Si ya está en nuestra base de datos global, selecciónela de la lista. Si es una institución nueva, ingrese el nombre completo y ClimMob agregará una etiqueta "-nueva afiliación".
*	Rol: Puede seleccionar múltiples roles para un mismo colaborador. Este campo sigue el Esquema de Metadatos DataCite, asegurando que los roles estén estandarizados para la citación de datos a nivel global.
*	Actividades: Especifique las tareas específicas realizadas por el colaborador. Esta selección se basa en la CRediT (Taxonomía de Roles de Colaboradores), que permite un alto nivel de granularidad para identificar contribuciones específicas (por ejemplo, Curación de datos, Investigación, Software, etc.).

### 2.	Financiadores

Esta nueva sección dedicada le permite registrar el apoyo financiero detrás de su ensayo. Mantener registros precisos de financiamiento es crucial para la transparencia, el cumplimiento de los requisitos de los donantes y la presentación de informes institucionales.

Si su proyecto recibió apoyo financiero externo, puede documentar múltiples fuentes proporcionando los siguientes detalles para cada una:

*	Nombre del financiador: Busque el nombre del donante o institución que proporciona los fondos. El sistema incluye una lista predefinida de organizaciones financiadoras globales para garantizar la consistencia.
*	Título de la subvención: Ingrese el nombre oficial de la subvención o proyecto tal como se especifica en el acuerdo de financiamiento.
*	Número de subvención: Proporcione el código de identificación único o número de referencia asignado por el financiador a esta subvención específica.
**Nota:** Si su investigación es apoyada por múltiples donantes, utilice el botón "+ Agregar otro" para crear una entrada separada para cada fuente de financiamiento.

### 3.	Diseño experimental

Este formulario consolida la estructura técnica del ensayo con su alineación estratégica. Le permite documentar todo, desde la disposición física de las parcelas hasta los mercados específicos que la investigación pretende abordar.

En este formulario, deberá especificar:

*	Tamaño de la parcela: Indique si se utilizó un tamaño de parcela estándar en todo el ensayo. En caso afirmativo, proporcione el área en metros cuadrados (m2).
*	Observaciones sobre el diseño: Un espacio para documentar cualquier observación o nota específica sobre el diseño físico de la parcela.
*	Diseño experimental: Seleccione los diseños estadísticos o metodológicos aplicados en el ensayo (por ejemplo, bloques incompletos, diseños aleatorizados, etc.).
*	Características especiales: Describa cualquier elemento único, como metodologías innovadoras, uso de tecnología avanzada o condiciones ambientales específicas que influyeron en la ejecución del ensayo.
*	Segmentos de mercado: Identifique los segmentos de mercado específicos asociados con el proyecto. Estas opciones están sincronizadas con la Plataforma Global de Inteligencia de Mercado (GloMIP) (https://glomip.cgiar.org/).
*	IDs de perfil de producto objetivo (TPP): Asocie el proyecto con IDs de TPP específicos de la plataforma GloMIP. Esto garantiza que los resultados del ensayo estén directamente vinculados a objetivos de mejoramiento global estandarizados y requisitos de producto.

### 4.	Genotipos

Esta sección proporciona un perfil técnico detallado de las tecnologías que se están evaluando. Para ahorrar tiempo y garantizar la consistencia, ClimMob lista automáticamente los genotipos que incluyó durante la configuración del proyecto.

Su tarea en este formulario es revisar la lista generada automáticamente y completar los campos descriptivos. Si bien esta información se utiliza para fines de documentación y metadatos —y no afecta los resultados estadísticos del ensayo— es vital para la interpretación a largo plazo de los datos.

Para cada genotipo, debe proporcionar:

*	Nombre del genotipo: El nombre original tal como está registrado en el proyecto.
*	Nombre final del genotipo: Utilice este campo si necesita estandarizar el nombre para el informe final o la publicación.
*	Tipo de entrada: Clasifique el material (por ejemplo, testigo histórico, testigo del agricultor, testigo comercial, entrada de evaluación, candidato a liberación, etc.).

Tabla 1. Opciones de tipo de entrada utilizadas en ensayos en finca o de mejoramiento y sus descripciones.

| Opción de tipo de entrada | Descripción |
|---------------------------|-------------|
| Testigo histórico | Una variedad que fue ampliamente utilizada en el pasado pero que ya no es la opción principal. Se utiliza para medir la ganancia genética a lo largo del tiempo. |
| Testigo del agricultor | La variedad local o material actualmente manejado y preferido por los agricultores en el área del ensayo. Esencial para calcular las "tasas de victoria". |
| Testigo comercial | Una variedad líder actualmente disponible en el mercado local. Se utiliza para comparar el desempeño de nuevos materiales con las mejores opciones comerciales actuales. |
| Testigo comparativo | Una entrada específica utilizada como referencia para ciertos rasgos (por ejemplo, una variedad conocida tolerante a la sequía utilizada para comparar nuevas líneas tolerantes a la sequía). |
| Entrada de evaluación | El material experimental principal, línea o tecnología que se prueba en el ensayo para su posible adopción o mejoramiento adicional. |
| Candidato a liberación | Una línea avanzada que ha demostrado un desempeño superior y se encuentra en las etapas finales del proceso regulatorio oficial para su liberación comercial. |
| Candidato a reemplazo | Un material específico destinado a reemplazar una variedad existente que se ha vuelto susceptible a plagas, enfermedades o condiciones climáticas cambiantes. |


*	Año de liberación: Si aplica, el año en que la variedad fue oficialmente liberada.
*	Año de cruzamiento: El año en que se realizó el cruce específico (para líneas de mejoramiento).
*	Origen: La fuente geográfica o institucional del material genético.
*	Rasgos objetivo: Especifique las características clave que se están evaluando (por ejemplo, tolerancia a la sequía, resistencia a plagas, rendimiento).

Tabla 2. Opciones de rasgos objetivo utilizadas para clasificar el enfoque principal de evaluación en ensayos en finca o de mejoramiento.

| Opción de rasgo objetivo | Descripción |
|--------------------------|-------------|
| Tolerancia a la sequía | La capacidad del genotipo para mantener el crecimiento y la productividad durante períodos de baja disponibilidad de agua o estrés hídrico significativo. |
| Resistencia a plagas | La capacidad del material para resistir o minimizar los daños causados por insectos u otras plagas animales. |
| Resistencia a enfermedades | La capacidad de la planta para prevenir o recuperarse de infecciones causadas por patógenos como hongos, bacterias o virus. |
| Calidad del producto | Características relacionadas con el uso final del cultivo, incluyendo contenido nutricional, sabor, textura, apariencia o cualidades de procesamiento industrial. |
| Rendimiento | La cantidad total de producto cosechado (por ejemplo, grano, tubérculos, fruta) por unidad de área, que representa la productividad general. |
| Otro | Utilice esta opción para rasgos específicos no cubiertos anteriormente, como tolerancia al frío, madurez temprana o resistencia a la salinidad del suelo. (Especifique en la columna Otros rasgos). |

*	Observaciones: Un campo de texto libre para cualquier nota técnica adicional u observaciones específicas de ese genotipo.
* Enlace de referencias externas: Vínculos a fuentes externas que proporcionan información adicional sobre el genotipo.

### 5.	Reclutamiento de participantes

Comprender cómo se seleccionan y comprometen los participantes es fundamental para la validez estadística y la integridad ética de un ensayo tricot. Este formulario utiliza campos de selección múltiple para documentar el proceso de muestreo y reclutamiento con precisión.

Complete las siguientes secciones seleccionando todas las opciones que apliquen a su proyecto:

*	Cálculo del tamaño de la muestra: Seleccione los métodos utilizados para determinar el número de participantes. Esto proporciona transparencia sobre si el ensayo tiene suficiente poder estadístico.

Tabla 3. Opciones de cálculo del tamaño de la muestra utilizadas para documentar cómo se determinó el número de participantes en ensayos en finca o de mejoramiento.

| Opciones de cálculo del tamaño de la muestra | Descripción |
|----------------------------------------------|-------------|
| Calculadora de tamaño de muestra de ClimMob | El tamaño de la muestra se determinó utilizando la herramienta calculadora integrada de ClimMob/Tricot. |
| Análisis de poder estadístico | Determinación del número mínimo de participantes necesarios para garantizar que el ensayo tenga suficiente fortaleza estadística para detectar de manera confiable diferencias significativas entre genotipos. |
| Modelo de Plackett-Luce | Estimado específicamente para ensayos que utilizan el modelo Plackett-Luce para comparaciones de clasificación o elección. |
| Basado en disponibilidad de semillas | El número de participantes estuvo limitado por la cantidad real de semillas o unidades de tecnología disponibles. |
| Número objetivo acordado con donantes/proyecto | El tamaño fue dictado por los objetivos del proyecto o acuerdos formales con donantes en lugar de estadísticas. |
| Directrices o métodos publicados | Determinado siguiendo literatura científica establecida o directrices institucionales estandarizadas. |

*	Criterios de selección: Documente los atributos o requisitos específicos utilizados para elegir a los participantes (por ejemplo, género, experiencia agrícola o condiciones socioeconómicas).

Tabla 4. Opciones de criterios de selección utilizadas para documentar cómo se identificaron y reclutaron los participantes para ensayos en finca o de mejoramiento.

### 7.	Recopilación de datos

Este formulario documenta el flujo práctico de información desde el campo hasta su base de datos. Registrar con precisión estos métodos es vital para evaluar la calidad de los datos y comprender el nivel de interacción entre investigadores y participantes.

Complete las siguientes dos categorías seleccionando todas las opciones que apliquen:

*	Método de recopilación de datos: Especifique el método de interacción empleado para recopilar información de los participantes.

Tabla 12. Opciones de método de recopilación de datos utilizadas para documentar cómo se recopilaron las observaciones del ensayo y las respuestas de los participantes en ensayos en finca o de mejoramiento.

| Opciones de método de recopilación de datos | Descripción |
|---------------------------------------------|-------------|
| Llamadas telefónicas directas | Datos recopilados de forma remota mediante llamadas telefónicas realizadas directamente a los participantes por el equipo del proyecto. |
