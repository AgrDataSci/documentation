## Introdução

A documentação do ensaio é uma etapa fundamental para garantir que os registros do seu projeto estejam completos e prontos para análise. Este recurso do ClimMob permite que você acompanhe todos os aspectos essenciais do seu ensaio por meio de um conjunto de formulários.

Você pode começar a preencher os formulários a qualquer momento durante o projeto, desde a sua criação. Alguns formulários são tipicamente preenchidos no início, enquanto outros são preenchidos ao final. **Nota: todos os formulários devem ser concluídos antes de prosseguir para a etapa de Análise de Dados e baixar relatórios.**

Como preencher os formulários:

Para proporcionar máxima flexibilidade mantendo dados padronizados, os formulários incluem os seguintes recursos:

*	Opções de seleção múltipla: A maioria dos campos permite que você escolha mais de uma resposta. Procure a dica "Selecione todas as opções que se aplicam" para documentar casos em que vários métodos ou critérios foram utilizados (por exemplo, combinando diferentes locais de recrutamento).
*	A categoria "Outro": Se o seu método ou recurso específico não estiver listado no menu suspenso, selecione "Outro". Isso abrirá uma caixa de texto dedicada para que você forneça uma descrição personalizada, garantindo que cada detalhe das suas operações de campo seja registrado.
*	Não aplicável: Se uma pergunta específica não se aplica ao escopo do seu projeto, você pode selecionar a opção "Não aplicável" para prosseguir.

## Estrutura

A seção de documentação do ensaio inclui os seguintes oito formulários:

### 1.	Colaboradores

Documente as organizações, pesquisadores ou instituições envolvidas no projeto, incluindo seus papéis e responsabilidades. Isso ajuda a reconhecer as contribuições e garante transparência.

**Nota:** Este formulário é exclusivo para colaboradores técnicos e operacionais. Instituições financiadoras ou doadores não devem ser listados aqui, pois possuem uma seção dedicada na documentação.

Ao adicionar um colaborador, você deve fornecer os seguintes detalhes:

*	Nome do colaborador: Você pode pesquisar usuários existentes do ClimMob. Se a pessoa tiver um perfil, seu nome aparecerá para seleção. Se ela não estiver no sistema, você pode inserir o nome completo e o sistema a identificará como "colaborador externo".
*	Setor: Especifique o setor profissional ou industrial ao qual o colaborador pertence.
*	Organização: Comece a digitar a afiliação. Se já estiver em nosso banco de dados global, selecione-a na lista. Se for uma nova instituição, insira o nome completo e o ClimMob adicionará uma etiqueta "-nova afiliação".
*	Função: Você pode selecionar múltiplas funções para um único colaborador. Este campo segue o DataCite Metadata Schema, garantindo que as funções sejam padronizadas para citação global de dados.
*	Atividades: Especifique as tarefas específicas realizadas pelo colaborador. Esta seleção é baseada na CRediT (Taxonomia de Funções de Contribuidores), que permite um alto nível de granularidade na identificação de contribuições específicas (por exemplo, Curadoria de dados, Investigação, Software, etc.).

### 2.	Financiadores

Esta nova seção dedicada permite registrar o apoio financeiro por trás do seu ensaio. Manter registros precisos de financiamento é crucial para a transparência, conformidade com os requisitos dos doadores e relatórios institucionais.

Se o seu projeto recebeu apoio financeiro externo, você pode documentar múltiplas fontes fornecendo os seguintes detalhes para cada uma:

*	Nome do financiador: Pesquise o nome do doador ou instituição que fornece os recursos. O sistema inclui uma lista pré-preenchida de organizações financiadoras globais para garantir consistência.
*	Título da bolsa/subvenção: Insira o nome oficial da bolsa ou projeto conforme especificado no acordo de financiamento.
*	Número da bolsa/subvenção: Forneça o código de identificação único ou número de referência atribuído pelo financiador a esta bolsa específica.
**Nota:** Se a sua pesquisa for apoiada por múltiplos doadores, use o botão "+ Adicionar outro" para criar uma entrada separada para cada fonte de financiamento.

### 3.	Delineamento experimental

Este formulário consolida a estrutura técnica do ensaio com seu alinhamento estratégico. Ele permite documentar desde o layout físico das parcelas até os alvos de mercado específicos que a pesquisa pretende abordar.

Neste formulário, você precisará especificar:

*	Tamanho da parcela: Indique se um tamanho padrão de parcela foi utilizado em todo o ensaio. Em caso afirmativo, forneça a área em metros quadrados (m2).
*	Observações sobre o delineamento: Um espaço para documentar quaisquer observações ou notas específicas sobre o delineamento físico das parcelas.
*	Delineamento experimental: Selecione os delineamentos estatísticos ou metodológicos aplicados no ensaio (por exemplo, blocos incompletos, delineamentos aleatorizados, etc.).
*	Características especiais: Descreva quaisquer elementos únicos, como metodologias inovadoras, uso de tecnologia avançada ou condições ambientais específicas que influenciaram a execução do ensaio.
*	Segmentos de mercado: Identifique os segmentos de mercado específicos associados ao projeto. Essas opções estão sincronizadas com a Plataforma Global de Inteligência de Mercado (GloMIP) (https://glomip.cgiar.org/).
*	IDs de perfil de produto-alvo (TPP): Associe o projeto a IDs de TPP específicos da plataforma GloMIP. Isso garante que os resultados do ensaio sejam diretamente vinculados a metas globais padronizadas de melhoramento e requisitos de produto.

### 4.	Genótipos

Esta seção fornece um perfil técnico detalhado das tecnologias sendo testadas. Para economizar tempo e garantir consistência, o ClimMob lista automaticamente os genótipos incluídos durante a configuração do projeto.

Sua tarefa neste formulário é revisar a lista gerada automaticamente e completar os campos descritivos. Embora essas informações sejam usadas para fins de documentação e metadados — e não afetem os resultados estatísticos do ensaio — elas são vitais para a interpretação dos dados a longo prazo.

Para cada genótipo, você deve fornecer:

*	Nome do genótipo: O nome original conforme registrado no projeto.
*	Nome final do genótipo: Use este campo se precisar padronizar o nome para relatório final ou publicação.
*	Tipo de entrada: Classifique o material (por exemplo, testemunha histórica, testemunha do agricultor, testemunha comercial, entrada de avaliação, candidato ao lançamento, etc.).

Tabela 1. Opções de tipo de entrada utilizadas em ensaios no campo ou de melhoramento e suas descrições.

| Opção de tipo de entrada | Descrição |
|--------------------------|-----------|
| Testemunha histórica | Uma variedade amplamente utilizada no passado, mas que não é mais a escolha principal. Usada para medir o ganho genético ao longo do tempo. |
| Testemunha do agricultor | A variedade local ou material atualmente gerenciado e preferido pelos agricultores na área do ensaio. Essencial para calcular as "taxas de vitória". |
| Testemunha comercial | Uma variedade líder atualmente disponível no mercado local. Usada para comparar o desempenho de novos materiais com as melhores opções comerciais atuais. |
| Testemunha comparativa | Uma entrada específica usada como referência para determinadas características (por exemplo, uma variedade conhecida por tolerância à seca usada para comparar novas linhagens tolerantes à seca). |
| Entrada de avaliação | O material experimental, linhagem ou tecnologia principal sendo testado no ensaio para potencial adoção ou melhoramento adicional. |
| Candidato ao lançamento | Uma linhagem avançada que demonstrou desempenho superior e está nas etapas finais do processo regulatório oficial para lançamento comercial. |
| Candidato à substituição | Um material específico destinado a substituir uma variedade existente que se tornou suscetível a pragas, doenças ou mudanças climáticas. |


*	Ano de lançamento: Se aplicável, o ano em que a variedade foi oficialmente lançada.
*	Ano de cruzamento: O ano em que o cruzamento específico foi realizado (para linhagens de melhoramento).
*	Origem: A fonte geográfica ou institucional do material genético.
*	Características-alvo: Especifique as características-chave sendo avaliadas (por exemplo, tolerância à seca, resistência a pragas, produtividade).

Tabela 2. Opções de características-alvo utilizadas para classificar o foco principal de avaliação em ensaios no campo ou de melhoramento.

| Opção de característica-alvo | Descrição |
|------------------------------|-----------|
| Tolerância à seca | A capacidade do genótipo de manter o crescimento e a produtividade durante períodos de baixa disponibilidade de água ou estresse hídrico significativo. |
| Resistência a pragas | A capacidade do material de suportar ou minimizar danos causados por insetos ou outros animais-praga. |
| Resistência a doenças | A capacidade da planta de prevenir ou se recuperar de infecções causadas por patógenos como fungos, bactérias ou vírus. |
| Qualidade do produto | Características relacionadas ao uso final da cultura, incluindo conteúdo nutricional, sabor, textura, aparência ou qualidades de processamento industrial. |
| Produtividade | A quantidade total de produto colhido (por exemplo, grãos, tubérculos, frutas) por unidade de área, representando a produtividade geral. |
| Outro | Use esta opção para características específicas não cobertas acima, como tolerância ao frio, maturação precoce ou resistência à salinidade do solo. (Especifique na coluna Outras características). |

*	Observações: Um campo de texto livre para quaisquer notas técnicas adicionais ou observações específicas daquele genótipo.
* Link de referências externas: Links para fontes externas que fornecem informações adicionais sobre o genótipo.

### 5.	Recrutamento de participantes

Entender como os participantes são selecionados e engajados é fundamental para a validade estatística e a integridade ética de um ensaio tricot. Este formulário usa campos de seleção múltipla para documentar o processo de amostragem e recrutamento com precisão.

Preencha as seguintes seções selecionando todas as opções que se aplicam ao seu projeto:

*	Cálculo do tamanho da amostra: Selecione os métodos utilizados para determinar o número de participantes. Isso fornece transparência sobre se o ensaio tem poder estatístico suficiente.

Tabela 3. Opções de cálculo do tamanho da amostra utilizadas para documentar como o número de participantes foi determinado em ensaios no campo ou de melhoramento.

| Opções de cálculo do tamanho da amostra | Descrição |
|-----------------------------------------|-----------|
| Calculadora de tamanho de amostra do ClimMob | O tamanho da amostra foi determinado usando a ferramenta calculadora integrada do ClimMob/Tricot. |
| Análise de poder estatístico | Determinação do número mínimo de participantes necessários para garantir que o ensaio tenha força estatística suficiente para detectar diferenças significativas entre genótipos de forma confiável. |
| Modelo de Plackett-Luce | Estimado especificamente para ensaios que utilizam o modelo de Plackett-Luce para comparações de classificação ou escolha. |
| Baseado na disponibilidade de sementes | O número de participantes foi limitado pela quantidade real de sementes ou unidades de tecnologia disponíveis. |
| Número-alvo acordado com doadores/projeto | O tamanho foi ditado por metas do projeto ou acordos formais com doadores, em vez de estatísticas. |
| Diretrizes ou métodos publicados | Determinado seguindo literatura científica estabelecida ou diretrizes institucionais padronizadas. |

*	Critérios de seleção: Documente os atributos ou requisitos específicos usados para escolher os participantes (por exemplo, gênero, experiência agrícola ou condições socioeconômicas).

Tabela 4. Opções de critérios de seleção utilizadas para documentar como os participantes foram identificados e recrutados para ensaios no campo ou de melhoramento.

| Opções de critérios de seleção | Descrição |
|--------------------------------|-----------|
| Com base em estudos anteriores ou conjuntos de dados existentes | Os participantes foram selecionados com base em resultados de pesquisas anteriores ou usando dados existentes que identificaram grupos ou áreas geográficas relevantes. |
| Conhecimento e habilidades para a tarefa | A seleção foi baseada na expertise técnica ou habilidades específicas necessárias para executar as atividades do ensaio de forma eficaz. |
| Gênero | Usado quando o projeto visa um equilíbrio de gênero específico ou tem como alvo um grupo de gênero específico (por exemplo, com foco em mulheres agricultoras). |
| Experiência com a cultura em estudo | Os participantes foram incluídos por terem um histórico comprovado no cultivo ou manejo da cultura específica sendo avaliada. |
| Características domiciliares de dados de levantamento | A seleção foi orientada por indicadores no nível domiciliar, como dados demográficos, tamanho das terras ou status socioeconômico coletados por meio de pesquisas. |
| Seleção aleatória | Os participantes foram escolhidos por meio de procedimentos formalizados de amostragem (aleatória, intencional ou aberta) para garantir imparcialidade científica. |
| Seleção a partir de listas ou registros pré-existentes de agricultores | Selecionados a partir de cadastros existentes, associações em cooperativas ou grupos comunitários organizados. |
| Interesse no projeto | A seleção foi baseada na motivação expressa pelos participantes e no alinhamento com os objetivos específicos do projeto. |
| Participação voluntária | Os participantes se autosselecionaram ao se voluntariar, frequentemente motivados pela curiosidade ou pelo desejo de testar novas práticas agrícolas. |
| Amostragem hierárquica ou em múltiplos estágios | Definida por meio de níveis de seleção aninhados (por exemplo, escolha de distritos, depois comunidades, depois agricultores). |

*	Abordagem de recrutamento: Especifique como você entrou em contato com os potenciais participantes, como anúncios públicos abertos ou convites diretos por meio de organizações de agricultores.

**Dica profissional:** Se o seu método específico não estiver listado em um menu suspenso, você geralmente pode selecionar "Outro" para fornecer uma descrição personalizada, garantindo que nenhum detalhe das suas operações de campo seja omitido.

### 6.	Capacitação

Esta seção documenta as atividades de treinamento e capacitação realizadas com os participantes. A documentação adequada da capacitação é essencial para garantir a confiabilidade dos dados de ciência cidadã coletados e para reconhecer o processo de transferência de conhecimento.

Preencha os seguintes campos selecionando todos os métodos e tópicos que se aplicam:

*	Explicação da abordagem tricot: Selecione os métodos usados para explicar a lógica da metodologia tricot (por exemplo, classificação cega, os pacotes "A, B, C") aos participantes.

| Visitas individuais domiciliares | Explicação direta e personalizada conduzida nos lares dos participantes. |

*	Instruções do ensaio: Identifique os tipos específicos de orientação técnica fornecida, como manejo agronômico, configuração do ensaio ou protocolos de avaliação sensorial.

### 7.	Coleta de dados

Este formulário documenta o fluxo prático de informações do campo para o seu banco de dados. Registrar com precisão esses métodos é vital para avaliar a qualidade dos dados e entender o nível de interação entre pesquisadores e participantes.

Preencha as duas categorias a seguir selecionando todas as opções que se aplicam:

*	Método de coleta de dados: Especifique o método de interação empregado para coletar informações dos participantes.

Tabela 12. Opções de método de coleta de dados utilizadas para documentar como as observações do ensaio e as respostas dos participantes foram coletadas em ensaios no campo ou de melhoramento.

| Opções de método de coleta de dados | Descrição |
|-------------------------------------|-----------|
| Ligações telefônicas diretas | Dados coletados remotamente por meio de ligações telefônicas feitas diretamente aos participantes pela equipe do projeto. |
| Visitas às propriedades | Dados coletados presencialmente nos campos dos agricultores por enumeradores, agentes de desenvolvimento ou equipe do projeto. |
