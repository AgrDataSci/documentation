# Exemplo de design: Protocolo de ensaio com feijão

> Kauê de Sousa

## Introdução

Para ilustrar como desenhar um experimento tricot, esta seção fornece uma visão geral das informações básicas
que serão coletadas durante um ensaio com feijão. Características e
variáveis adicionais podem ser incluídas, mas isso precisará ser feito pelo gestor
do projeto no ClimMob.

O POP de feijão indica os momentos de coleta de dados durante
os ensaios e as variáveis e características coletadas em cada momento de
coleta de dados. Os agricultores avaliam variedades em seus ensaios on-farm
e fornecem observações comparativas classificando as variedades com base em
seu desempenho ao longo do crescimento e nas qualidades pós-colheita,
incluindo preferências de sabor e consumo.

Um POP separado para análise de consumidores de feijão será desenvolvido para
compreender o sabor e as preferências de consumidores não-agricultores do tricot,
a fim de fortalecer decisões de melhoramento inclusivas e informadas.

Uma visão geral mais detalhada das etapas necessárias para desenvolver um projeto de
ensaio on-farm usando o tricot [ClimMob](https://climmob.net/) está
disponível aqui:
