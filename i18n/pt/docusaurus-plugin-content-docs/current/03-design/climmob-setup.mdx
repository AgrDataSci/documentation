## Configurando um novo projeto no ClimMob

Você já deve ter criado uma conta de usuário no ClimMob [(veja as instruções de como fazer isso aqui).](/preparation/introduce-climmob#create-a-climmob-account) Para começar a trabalhar com o ClimMob, o primeiro passo é criar um novo projeto. Você pode fazer isso de duas maneiras: acessando a seção Visão Geral do Projeto e clicando em Criar novo projeto, ou navegando até Todos os projetos e selecionando Adicionar novo projeto. Em ambos os casos, será solicitado que você preencha um formulário curto com os principais detalhes do projeto. Uma vez criado, você pode retornar a qualquer momento para atualizar ou ajustar as configurações do projeto.

Para configurar um perfil para o seu projeto tricot, preencha os seguintes campos:

1) Informações gerais

* Nome do projeto: Nome único e mais descritivo para o projeto. Recomendamos incluir a tecnologia, o ano ou período, e a localização, para distinguir o projeto dos demais quando você gerencia múltiplos projetos. Por exemplo: Feijao_Honduras_2019_temporada1

* ID do projeto: Identificador curto e único do projeto. Por exemplo, suas iniciais e o ano do projeto: JV19.
* Descrição: Adicione mais detalhes sobre o projeto.
* Palavras-chave: Para tornar o seu projeto pesquisável por outros usuários, insira até X palavras-chave que definem o seu projeto. Exemplos: "feijão", "Honduras".
* Coordenador do ensaio: Seu nome completo, começando pelo primeiro nome, todos os nomes separados por espaço. Por padrão, já está preenchido com seus dados. Altere caso o coordenador do ensaio seja outra pessoa.
* Endereço de e-mail: Seu endereço de e-mail.
* Afiliação: Selecione uma ou crie uma nova afiliação, caso nenhuma das opções se aplique à sua organização.

2) Informações geográficas

* Selecione o país onde o projeto será realizado

3) Participantes

* Número de participantes: Informe quantos participantes farão parte deste projeto. Por exemplo: 200. Se você ainda não sabe o número exato, é melhor escolher um número mais alto do que mais baixo (mas ainda razoável, pois do contrário o ClimMob realizará muito processamento desnecessário posteriormente).

4) Rótulos das opções de tecnologia

* Número de opções de tecnologia que cada participante compara: Por padrão, este valor é '3' e não pode ser alterado. É um lembrete de que em um projeto tricot, cada participante receberá 3 opções de tecnologia para comparar.
* Nome dado aos 3 itens que cada participante compara: por padrão os nomes são "Opção A, Opção B e Opção C", mas o coordenador do ensaio pode decidir alterá-los para algo com o qual os participantes se identifiquem melhor, como números, cores ou formas.

5) Tipo de projeto

* Você pode indicar se o projeto é um projeto de treinamento. Isso significa que o projeto foi criado para fins educacionais — como prática, demonstrações ou atividades de curso — e não tem a intenção de coletar dados reais no campo.
* Existem três opções para o local experimental: teste na fazenda, domicílio ou espaço público (por exemplo, mercado). Dependendo do local experimental selecionado, será necessário escolher entre diferentes unidades de análise e objetivos correspondentes (veja exemplos na caixa abaixo).
* Deseja criar seu projeto a partir de um modelo SOP? Selecione se aplicável ao seu projeto. [Leia mais sobre SOPs aqui.](/design/sops#introduction)
* Por fim, você pode selecionar até quatro idiomas nos quais os formulários para participantes serão disponibilizados, permitindo a coleta de dados multilíngue conforme necessário.

### Selecionar opções de tecnologia

Nesta seção, você pode especificar as opções de tecnologia que deseja comparar no seu experimento tricot. Por exemplo, se você deseja testar variedades de feijão, adicionaria aqui os nomes das variedades de feijão a serem testadas. Se deseja testar regimes de fertilização, adicionaria os nomes dos regimes de fertilização a serem testados.

Como fazer:

1. Na seção de visão geral do projeto, clique no botão verde Selecionar opções de tecnologia.

2. Você acessará a lista de tecnologias disponíveis na plataforma. Se a tecnologia de seu interesse estiver lá, basta clicar nela e acessar as diferentes opções (por exemplo, variedades).

3. Se a tecnologia de seu interesse não estiver lá, clique em + adicionar nova tecnologia. Esta ação irá redirecioná-lo para a biblioteca, onde você pode criar novas tecnologias.

### Preparar formulário de coleta de dados

Nesta seção, você define os diferentes momentos de coleta de dados para a avaliação no campo que os participantes irão realizar. Em cada momento, perguntas específicas serão feitas para capturar observações. É importante decidir:

* Quais características serão avaliadas nas opções de tecnologia selecionadas?
* Quando cada característica será avaliada durante o ciclo de plantio?

Uma vez configurados, esses formulários de coleta de dados orientarão os agentes de campo e os participantes durante o processo de avaliação.

Como fazer:

1. Na seção de definição do projeto, clique em Preparar coleta de dados. Aqui você pode adicionar os diferentes momentos de coleta de dados ao longo do ciclo de plantio.

2. Após adicionar os momentos de coleta de dados, vá ao painel direito (Momentos de coleta de dados ativos) e clique em Mostrar para visualizá-los.

3. Para cada momento de coleta de dados, arraste as perguntas desejadas do painel esquerdo (perguntas disponíveis na biblioteca) para o painel central (formulário de avaliação). Uma prévia das perguntas selecionadas aparecerá no painel direito (prévia) — role para baixo para ver todas as perguntas.

4. Se a pergunta que você precisa não estiver na biblioteca, clique em Adicionar nova pergunta e crie-a na seção mais relevante.

### Randomização de tecnologia

Após configurar os momentos de coleta de dados e as perguntas correspondentes, o próximo passo é criar pacotes de teste por meio da randomização de tecnologia. Esse processo garante que cada participante receba um conjunto equilibrado de opções de tecnologia para avaliação.

Como fazer:

1. Na seção de visão geral do projeto (lado direito da tela), clique em Gerar pacotes com opções de tecnologia para abrir o formulário de registro de participantes.

2. Definir combinações:

* Escolha se deseja incluir todas as opções de tecnologia ou apenas uma seleção.
* Defina quantos pacotes com cada opção de tecnologia serão gerados.
* Por padrão, todas as opções de tecnologia são incluídas e o mesmo número de pacotes é criado para cada uma.

**ATENÇÃO** Se você alterar o número de pacotes para uma tecnologia, deverá equilibrar o total adicionando ou subtraindo das demais para garantir o mesmo número geral de pacotes.

3. Revise os pacotes e confirme. Se a lista de pacotes não for confirmada, ela será perdida e você precisará repetir a randomização.

4. Uma vez confirmados, os documentos de randomização ficam disponíveis na seção Downloads:

* Lista de pacotes com códigos QR para o formulário de registro → necessária para a preparação dos pacotes de teste.
* Lista com pacotes de ensaio randomizados (Excel) → mostra as combinações de tecnologia atribuídas a cada pacote. Este arquivo é útil na preparação dos pacotes de teste. Não edite este arquivo.
