# Pacotes de teste

> Sofía Acuña, Marilyn Manrow, Brandon Madriz, Kauê de Sousa

### Preparar os pacotes de teste

Depois que suas tecnologias forem randomizadas no ClimMob [(clique aqui para a etapa de 'Randomização de tecnologias' no ClimMob)](/design/climmob-setup#technology-randomization), o próximo passo é criar os pacotes físicos com as tecnologias que os participantes utilizarão durante o teste cego.

Como fazer (três etapas):

1. Reunir os materiais

* Colete quantidade suficiente de cada opção de tecnologia que está sendo testada.
* Exemplo: Se você está testando variedades de sementes, reúna quantidades suficientes de cada tipo de semente.

2. Baixe as listas de pacotes do ClimMob (na seção Downloads):

* Lista de pacotes de teste randomizados → mostra qual combinação de três opções de tecnologia vai em cada pacote.
* Lista de pacotes com QR codes para registro de participantes → contém o número do pacote e seu QR code único.

3. Preparar e etiquetar os pacotes

* Monte cada pacote com o conjunto atribuído de três opções de tecnologia.
* Recorte a etiqueta correspondente (da lista de pacotes com QR codes).
* Cole a etiqueta com o número do pacote e o QR code no pacote antes de distribuí-lo aos participantes.

Cada pacote de teste deve conter os seguintes quatro elementos:

1. Um QR code gerado para cada pacote, que será utilizado como identificador único para rastrear todas as informações coletadas durante o ensaio. É importante instruir os agricultores a guardar este código durante toda a duração do ensaio. [Saiba mais sobre a geração de QR codes aqui.](/design/climmob-setup#technology-randomization)

2. Três sacos com quantidades iguais das opções de tecnologia (por exemplo, sementes, fertilizantes) ou instruções sobre como aplicar as opções de tecnologia alternativas (por exemplo, sistemas de preparo do solo), de acordo com a randomização gerada pelo ClimMob.

3. Um cartão de observação onde os testadores registrarão suas observações em campo. [Saiba mais sobre os cartões de observação aqui.](/design/climmob-setup#prepare-observation-cards)

4. Um folheto que explica todo o processo ao agricultor. [Ilustrações e outros materiais de apoio para comunicação com agricultores podem ser encontrados aqui.](/resources/resources#support_material)

### Atribuir e distribuir os pacotes

Depois de preparar os pacotes com as diferentes opções de tecnologia [(veja como fazer isso aqui)](/distribution/packages#prepare-the-trial-packages), é hora de ir ao campo para distribuí-los e registrar cada participante com o seu respectivo pacote de teste.

Como fazer:

Existem diferentes formas de fazer isso: você pode organizar uma reunião com todos os participantes ou visitá-los individualmente em seus locais.

**Usando o ODK Collect**

No mínimo, os seguintes dados básicos são necessários:
* QR code do pacote de teste
* Nome do testador (agricultor participante)

O código do pacote de teste utiliza um QR code gerado pelo ClimMob como identificador único do pacote ao longo do ensaio. O QR code é gerado assim que as tecnologias são definidas e a randomização é configurada. O implementador do projeto imprime os códigos (disponíveis na seção Downloads) e os cola em cada pacote. **Observação: os agricultores devem guardar o código do seu pacote (QR code) durante toda a duração do projeto.**

1. Abra o ODK Collect e obtenha o formulário de registro em branco.

2. Preencha o formulário com os dados do participante. O primeiro passo é escanear o QR code anexado ao pacote com as três opções de tecnologia que o participante está recebendo. Isso vincula o pacote ao perfil individual do participante.

3. Após concluir o preenchimento dos formulários, envie-os ao servidor.

**Papel** (NÃO RECOMENDADO, pois demanda significativamente mais tempo e é mais sujeito a erros):

1. Alternativamente, você pode registrar os participantes usando formulários em papel. Estes estão disponíveis em Downloads → Formulário de registro para impressão.

2. Insira os dados em um arquivo Excel. No menu principal (lado esquerdo), clique em Upload data (botão verde) → Create template. O modelo será gerado e ficará disponível em Downloads → Excel template for uploading registration form data.

3. Depois de preencher o modelo, volte ao menu principal, clique em Upload data (botão verde, lado esquerdo) e faça o upload do documento Excel.

Revisar, editar e concluir o registro:

* Clique no botão verde View data para revisar os dados enviados e editar se necessário.
* Clique no botão vermelho Finish registration assim que tiver registrado todos os participantes.

⚠️ Atenção: Esta etapa não pode ser desfeita, portanto, prossiga somente quando tiver certeza de que o registro está completo.
