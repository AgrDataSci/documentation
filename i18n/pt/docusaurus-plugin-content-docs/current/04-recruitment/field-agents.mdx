# Atribuir agentes de campo

> Sofía Acuña, Marilyn Manrow, Brandon Madriz, Kauê de Sousa

### Atribuir agentes de campo no ClimMob

Após você [criar um projeto no ClimMob e completar a Visão Geral do Projeto](/design/climmob-setup##create_project), você pode adicionar os agentes de campo que trabalharão neste projeto específico. Os agentes de campo são seus extensionistas em campo que se comunicarão com os participantes e posteriormente coletarão todas as observações do ensaio usando o aplicativo ODK Collect.

1.	Na seção Visão Geral do Projeto, clique em Atribuir agentes de campo.

2.	Se os agentes de campo com quem você deseja trabalhar já estiverem na lista à esquerda, basta selecionar aqueles com quem gostaria de trabalhar neste projeto.

3.	Se desejar adicionar novos agentes de campo, clique em +adicionar novo agente de campo. Isso irá redirecioná-lo para a biblioteca de agentes de campo, onde você pode adicionar as informações sobre um novo agente de campo.

*Observe que a senha e o nome de usuário do campo são necessários para o ODK Collect.
