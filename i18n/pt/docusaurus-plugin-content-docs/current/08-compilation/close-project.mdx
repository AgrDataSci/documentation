# Encerramento de um projeto

>Sofía Acuña, Marilyn Manrow, Brandon Madriz

Após concluir a coleta de dados e atingir os objetivos do seu ensaio, o próximo passo é encerrar o projeto. Esta ação estabelece a transição de um espaço de trabalho ativo para um registro fechado, garantindo que seus dados permaneçam consistentes e prontos para análise, geração de relatórios ou uso a longo prazo.

Encerrar um projeto é o processo de converter um espaço de trabalho ativo em um registro permanente somente leitura. Embora um projeto possa ser encerrado a qualquer momento, recomenda-se fazê-lo somente após a conclusão de todos os objetivos da pesquisa.

## Quando você deve encerrar um projeto?

Encerrar um projeto é um marco importante. Recomenda-se prosseguir somente quando:

* Todos os dados tiverem sido coletados e verificados.
* Os detalhes do projeto e a documentação do Ensaio estiverem completos.

**1. Permissões de usuário**

Somente o proprietário do projeto tem autoridade para encerrá-lo. Colaboradores com acesso compartilhado não podem realizar esta ação.

**2. Lista de verificação pré-encerramento**

Antes de encerrar, verifique os seguintes status:

* Conclusão dos dados: Confirme que todos os registros de dados estão precisos e que não são esperadas mais entradas.
* Perfil do projeto: Revise os principais detalhes do projeto (por exemplo, nome, descrição e configurações do ensaio), pois estes serão bloqueados.
* Documentação do Ensaio: Esta etapa deve estar marcada como Concluída. Embora não seja obrigatória para encerrar o projeto, é necessária para habilitar o módulo de Análise.

**3. O processo de confirmação**

Ao selecionar "Encerrar projeto", uma tela de confirmação com alertas importantes será exibida:

* Bloqueio permanente de dados: Todos os registros de dados, metadados e configurações do projeto serão bloqueados e não poderão ser modificados.
* Requisito do módulo de Análise:
  + Se a Documentação do Ensaio estiver incompleta, você será alertado de que o módulo de Análise não estará disponível após o encerramento do projeto.
  + Se não houver dados suficientes coletados, o sistema irá alertá-lo de que o módulo de Análise pode não gerar resultados.
* Aviso de conflitos não resolvidos: Se houver envios com conflitos, você será informado de que a análise não pode ser gerada e que estes não poderão ser resolvidos após o encerramento do projeto.

**4. Pós-encerramento: Modo Somente Leitura**

Após a confirmação, o projeto entra no Modo Somente Leitura para garantir a integridade dos registros:

* Acessibilidade: Todas as informações do projeto, resultados e metadados permanecem disponíveis para visualização.
* Disponibilidade da Análise: Se a Documentação do Ensaio estiver concluída e houver envios válidos suficientes, o módulo de Análise permanece disponível após o encerramento do projeto.
* Restrições: A edição está desabilitada. Qualquer tentativa de modificar o projeto resultará em uma mensagem *Access Restricted (403)*.
* Notificação: Um e-mail é enviado ao proprietário do projeto e aos administradores da 1000FARMS informando que o projeto foi encerrado.
