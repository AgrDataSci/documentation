# Compartilhe seu projeto no ClimMob

> Sofía Acuña, Marilyn Manrow, Brandon Madriz

O ClimMob permite que você colabore compartilhando seu projeto com outros usuários. Ao convidar alguém, você deve atribuir uma função que define o nível de acesso que essa pessoa terá:

*	Owner – Atribuído automaticamente à pessoa que criou o projeto. Os proprietários não podem ser alterados.
*	Admin – Controle total do projeto, incluindo permissão para compartilhá-lo com outras pessoas.
*	Editor – Pode modificar qualquer seção do projeto, mas não pode compartilhá-lo com novos usuários.
*	Member – Acesso somente leitura. Os membros podem visualizar todas as informações, mas não podem fazer alterações.

Como compartilhar um projeto com outros usuários:

1.	No ClimMob, abra a visão geral do projeto e vá até a seção Compartilhar projeto.

2.	Insira o e-mail do usuário que você deseja convidar.

3.	Selecione a função (Admin, Editor ou Member) que melhor se adapta ao nível de participação dessa pessoa.

4.	Confirme para compartilhar o projeto. O usuário convidado terá acesso de acordo com a função que você atribuiu.
