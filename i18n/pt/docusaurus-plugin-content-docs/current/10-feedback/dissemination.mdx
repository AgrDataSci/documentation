# Disseminação

> Retirado de van Etten et al. [-@vanEtten2020rtb], página 13.

A publicação em acesso aberto dos dados deve ser um objetivo do ensaio. O tricot já publicou um número considerável de conjuntos de dados provenientes de ensaios em campo de agricultores [@vanEtten2018;@Moyo2021;@deSousa2021]. Esses conjuntos de dados podem tornar-se importantes para outras investigações que os reutilizem. Kool et al. [-@Kool2020] apresentaram uma crítica incisiva aos testes em campo de agricultores em agronomia, especialmente a replicabilidade limitada de muitos ensaios, uma vez que os autores não relatam fatores contextuais (gestão das culturas) nem a amostragem de locais e agricultores participantes.

Da mesma forma, um estudo sobre PVS em culturas RTB revela que os ensaios em campo são frequentemente documentados de forma muito deficiente e que os dados quase não são publicados [@Valle2021]. A publicação de dados poderia tornar-se mais atrativa se fosse fácil de realizar e tivesse recompensas (citações de conjuntos de dados reutilizados por outros). A publicação de todos os dados dos ensaios poderia prevenir o chamado problema da gaveta, que significa que apenas determinados conjuntos de dados (por exemplo, análises inovadoras, resultados marcantes) são publicados, o que leva a estatísticas enviesadas em meta-análises.

A abordagem tricot deve abordar estas questões facilitando e padronizando a forma como os ensaios em campo são documentados e publicados. A padronização deve ser realizada utilizando os conhecimentos dos estudos citados acima. Especificamente, os metadados sobre os ensaios poderiam ser padronizados e alguns elementos sobre o contexto do ensaio poderiam tornar-se elementos recomendados, facilmente disponíveis no software. Por exemplo, está a tornar-se cada vez mais claro que os históricos de uso das parcelas e a fertilização nas épocas anteriores das parcelas têm grande influência nas produções [@Njoroge2019;@Zingore2007]. Para isso, um esquema de metadados existente para experiências fenotípicas poderia ser adaptado [@Papoutsoglou2020]. Além disso, o processo de publicação de dados deve ser automatizado, incluindo o procedimento de anonimização (remoção de informações pessoais identificáveis, como nomes, endereços e números de telefone, bem como a agregação de dados geográficos a um nível suficiente para impedir a identificação).
