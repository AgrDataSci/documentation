# Checklist

### Esta tabela pode ser usada como um checklist para planejar um experimento tricot.
<a href={useBaseUrl('/pdfs/tricot_trial_checklist.pdf')} target="_blank" rel="noopener noreferrer">
  Clique aqui para abrir o checklist em formato PDF para impressão
</a>


| ✔ | Etapa            | Tarefa             | Ações Principais                                                                                           | Responsável             |
|---|------------------|-----------------|-----------------------------------------------------------------------------------------------------|-------------------------|
| ☐ | **1. Preparação** | Definir escopo     | Identificar problemas locais; selecionar opções de tecnologia; determinar critérios de avaliação; decidir área-alvo e número de agricultores | Pesquisadores + Implementadores |
| ☐ |                | Preparar materiais | Produzir sementes/insumos de qualidade; preparar fichas de observação, folhetos e materiais de treinamento             | Pesquisadores             |
| ☐ | **2. Desenho**  | Criar projeto no ClimMob | Registrar conta; configurar projeto usando o POP; designar agentes de campo; inserir opções de tecnologia; revisar perguntas de coleta de dados | Implementadores            |
| ☐ |                | Randomização e pacotes | Gerar pacotes de ensaio com códigos QR; etiquetar sacos; preparar conjuntos balanceados                              | Implementadores            |
| ☐ | **3. Recrutamento** | Seleção de agricultores | Identificar voluntários (homens/mulheres, diferentes idades e funções); garantir compromisso                            | Agentes de campo            |
| ☐ |                | Mobilização     | Divulgação por meio de reuniões, cartazes, boca a boca                                                         | Agentes de campo            |
| ☐ | **4. Distribuição** | Oficina de treinamento | Treinar agricultores no método tricot, configuração do ensaio e fichas de observação                                    | Implementadores + Agentes de campo |
| ☐ |                | Distribuir pacotes de ensaio | Fornecer pacotes com código QR contendo 3 opções, ficha de observação e folheto                              | Agentes de campo            |
| ☐ |                | Registrar agricultores | Usar o ODK Collect para registrar dados dos agricultores e código do pacote                                             | Agentes de campo            |
| ☐ | **5. Execução** | Ensaios na propriedade   | Agricultores plantam/manejam 3 parcelas lado a lado sob práticas normais                                      | Agricultores                 |
| ☐ | **6. Observação** | Avaliações em campo | Agricultores registram "melhor" e "pior" para cada critério nas fichas de observação                             | Agricultores                 |
| ☐ |                | Acompanhamento        | Fornecer lembretes/suporte por ligações/visitas; auxiliar no preenchimento das fichas se necessário                        | Agentes de campo            |
| ☐ | **7. Compilação** | Coletar dados     | Agentes de campo recolhem fichas de observação/dados; inserem via ODK Collect; fazem upload para o ClimMob                  | Agentes de campo            |
| ☐ | **8. Análise** | Processar dados     | Usar o ClimMob para gerar relatórios (rankings de tecnologia, análise de variáveis explicativas)                  | Implementadores            |
| ☐ |                | Resultados          | Produzir relatório de análise (pesquisadores) + infosheets (agricultores)                                          | Implementadores            |
| ☐ | **9. Retroalimentação** | Oficinas finais  | Compartilhar resultados gerais; distribuir infosheets; facilitar discussões em grupo com agricultores                     | Implementadores + Agentes de campo |
| ☐ |                | Treinamento prático | Fornecer aulas adicionais de agronomia (ex.: armazenamento de sementes)                                              | Implementadores            |
| ☐ | **10. Avaliação** | Avaliar ciclo     | Coletar feedback de agricultores e agentes; avaliar indicadores (taxa de conclusão, proporção por gênero, adoção, participação repetida, difusão) | Pesquisadores + Implementadores |
| ☐ |                | Planejar próximo ciclo  | Ajustar portfólio de tecnologias (retirar opções ruins, adicionar novas); ampliar participação de agricultores                      | Todas as partes interessadas        |
